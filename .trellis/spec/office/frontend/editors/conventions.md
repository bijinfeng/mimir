# packages/office/src/editors —— 各格式的编辑器

`DocxEditor` / `XlsxEditor` / `PptxEditor` / `HtmlEditor` / `PdfEditor` /
`MarkdownEditor`（`src/editors/`）。markdown 的宿主方言（Tiptap 扩展配置）
在 `packages/renderer/src/editor`；外壳在 `../shell`。父层 `.trellis/spec/office/engine/index.md`
与[项目规则](../../../project/rules.md)仍然适用。

六格式工具栏通过可见分类和命令组呈现已有可执行操作；窄编辑列保留分类，按命令区实际宽度从右侧逐组压缩为各自具名菜单，保留高频直接控件，不把所有组移进总“更多”。压缩菜单保持至少72px宽与单行标签；全部折叠后仍放不下时，仅命令组条局部横滚，不能把文字挤成竖排或让整页溢出。通常中栏优先折叠后完整显示，不以横滚替代分组适配。此规则来自 2026-10-16 用户追加样式门槛，以及真实 690px 中栏裁切和420px七组标签挤压证据。用选中态、当前值、上下文工具和禁用原因表达操作条件；`footer` 用于实际输入或临时失败，不承载无选中时的教程。查找快捷键切到其输入框所在分类后再聚焦，避免分类切换导致承诺失效。保存与 Agent 始终调用同一编辑原语，工具栏重排不改原件语义。

DOCX 的首尾工作台留白应加在 `.mimir-docx-scroll > .editor-scroll` 上，并随滚动内容移动；不要用 `.page-wrap` 或 `.doc-page` 的内边距实现。前者会改变分页原点，后者会改变纸张几何。修改后要在长文档中分别滚到首页和末页，确认纸张外侧留白与页间灰带。

Markdown 正文的 `/` 菜单在 `markdown-slash.ts`。候选项先查活编辑器的
`editor.schema.nodes`，只显示宿主方言支持的节点；选中时先删 `/query`，再通过
`uiOp(editor, op)` 写入，和 Agent 的 `runOps` 共用验证与撤销语义。新增候选时须用
宿主实际方言测试「选择命令 → 节点变化 → `getMarkdown()` 读回」；没有节点或
渲染器的数学、Mermaid、WaveDrom 命令不能只加一条菜单项。

PDF 内容编辑的磁盘基线不是 `useSource.bytes`：后者始终是本次加载的原件，即使
`source.save()` 已成功写出新字节也不会替换。`PdfEditor` 须按文档与原件身份记录
最近一次成功保存的**实际字节**，在待保存插字重放后据此判断内容 dirty；页面结构
仍与 `PdfEdit.file` 比较。删除最后一段新插字若回到已保存字节，须保留该工作副本并
清除 dirty；若回到尚未保存过的加载原件，才能清空工作副本。保存期间继续编辑时，
完成写盘的旧字节仍要成为新基线，新插字只能以同一次保存生成的字节重放；异步
页面序列化期间若画布版本变化，旧保存须在写盘前拒绝。回归测试至少覆盖
「保存 → 插字 → 删除」、「页面改动保存中 → 插字 → 删除」及独立 PDF 字节读回。

## XLSX 范围工具与画布合同（2026-10-16）

### 1. 适用范围

`XlsxEditor` 的手动范围工具与 Agent 共用当前画布句柄、版本和字节宿主；新增按钮前必须有对应画布反馈，不能仅凭保存后的 XML 宣称工具可用。

### 2. 签名

共享宿主为 `POST /api/conversations/xlsx-agent/apply-ops`；内部 `XlsxHostRequest` 含 `documentId`、`bytes: Uint8Array`、`expectedVersion: number`、`ops: unknown[]`、可选 `signal`。结果为 `{ bytes, version, changedCells, touchedEntries }`。

### 3. 数据合同

- 范围用 A1 记法、工作表用持久 ID；宿主验证固定上游 DSL 白名单。当前可物化编辑/读取上限为 2000 格；不能把稀疏行数组长度当最大实际行号。
- `xlsx-format.ts` 从 `cellXfs` 解析基础字体/填充/边框/对齐和数字格式。编辑框保留原始数值或公式；数字、布尔和单引号前缀文本按实际输入类型写回。日期必须遵守原件日期系统。
- 排序保留完整单元格 XML（含富文本、样式和类型），并平移普通相对公式，绝对引用保持；目标行属性和范围外格保留。
- 隐藏表保持可发现并标注“隐藏”；工作簿必须至少有一张可见表。异步执行和保存期间，相关控件必须禁用并解释状态。

### 4. 校验与错误

排序列不在范围内、数据不足两行、超过上限、受保护表、shared/array 公式或尚未迁移的地址关联结构（合并、批注、超链接、条件格式、数据验证、表格、筛选）均须预拒绝，保留原件。宿主迟到结果遇人工编辑/切文档/版本变化不得覆盖当前画布；失败保留 dirty。

### 5. 示例

- 正常：`A3:B3` 改斜体/填充/居中，即时网格、当前值和保存重开一致。
- 基线：General 数字不被猜成日期，未改 C3 公式及缓存保持原样。
- 拒绝：含 shared formula 的排序不能降级成只搬值的排序。

### 6. 必需验证

`XlsxEditor.test.tsx` 验证真实控件、当前值、画布和两次保存；`xlsx-agent-host.test.ts` 验证公式/样式排序、复杂结构拒绝和未改部件；`xlsx.test.ts` 验证格式与日期系统。浏览器/桌面实际界面证据与测试结果分别记录在格式矩阵中。

### 7. 正反例

错误：把上游 `sort_range` 展开为仅写 `value` 的 `set_cell`，导致公式和样式丢失。正确：先验证关联结构，再搬移完整格 XML 和公式引用；不支持的结构明确拒绝。

### 8. XLSX 对象 Inspector 与网格显示

开始分类把同类命令收拢为字体与对齐、剪贴板、工作表、单元格、查找五组；工作表选择/命名/管理合组，查找输入与结果合组，行列与合并放入单元格组，剪切/格式刷并入剪贴板。宽区直接提供常用字形、当前字体与字号；窄区沿共用壳按实际宽度具名折叠，不能因新增能力持续增加同级分组。

图表/形状/图片/结构化表/透视使用文档区内320px Inspector；≤800px编辑区覆盖显示。背景必须用实色`--me-surface`，`--me-bar-bg`是半透明填充不能直接当覆盖面板背景。六类型tabs局部3×2布局，字段短标签与辅助说明分开；所有非primary ToolbarButton必须提供图标或可见文字，label仅是可访问名称。关闭/Escape恢复入口焦点，用户已转移到其他控件时不抢焦点。

默认工作表遵循有效且可见的workbookView.activeTab，否则首张可见；隐藏表仍可显式选择。源字节身份变化时重新使用该规则。对象锚点按实际EMU/行列尺寸绘制；稀疏行物化后须重算已有合并跨度。键盘跳转用mergeRef真实边界，不能把DOM rowSpan当Excel行号差；pointercancel、外部pointerup、失焦均结束拖选，第二指针不得接管首个拖选。

对象预览以实际渲染的 `colgroup > col`、`tbody > tr` 普通流轨道定位，保留原生行列索引并排除隐藏项；不能累加默认20px行高或测量 sticky 表头、跨格单元格来猜锚点。测量相对 stage 并除以其 zoom，EMU offset 仍按9525/px转换；行列尺寸或缩放变化须重测并清理观察器。仅无 DOM 布局时使用模型尺寸回退；完全隐藏的跨度不画虚假最小矩形。

结构化表样式由真实主题色、内置族或自定义dxf分层叠加，显式单元格填充/文字颜色与CF优先，样式只影响预览、不烘焙回cellXfs。CSV/TSV和剪贴板先准备预览，点击主操作才写入；异步文件读取卸载/换表后不得发布旧草稿。解析限制1MiB UTF-8、500行/100列/2000格，并处理BOM、CRLF、多行引号及空字段。

工作表形状图库仅列固定 `ADDABLE_SHAPE_TYPES` 白名单与 textbox，复用已有 Office 分组中文名称及几何；PPTX 专用线条不能泄漏到工作表插入。320px 对象 Inspector 保留搜索/分组、可见当前形状与位置、独立滚动及固定单一插入动作；选择不写文档，显式插入只发布一次原生 add_shape 和一次历史。源/文档/工作表变化、关闭或切换对象类型时取消待处理请求，自己的 busy 不取消自身。未知预设不能画通用矩形冒充；未建模的原件调整点、旋转、复杂填充和文字样式须明确说明预览有限，不改变未操作的原生 XML。

## DOCX 高级工具面板

### DOCX 受保护讨论

comments-only 原件只开放具名“管理批注”面板，不能通配解禁其他高级写工具。主正文继续只读，面板按当前讨论能力展示文字、回复、解决/重开及具体拒绝原因；无既有讨论时说明不能新增，新增与删除按钮保持准确禁用。切换讨论清除上一目标的回复草稿，不能将草稿带到另一讨论。

沿320px Inspector壳，以单列可见字段、内部滚动body和同级固定footer呈现；“保存批注修改”为单一primary，回复/解决/删除为次操作。ToolbarButton的primary自动显示label，调用处不得再放重复文案子节点。窄屏折叠菜单先关闭，Escape先关弹层再关面板，回当前可见入口。批注写入沿options-only脏状态与结构撤销；不要把正文Cmd+Z说明成可以撤销附加参数。

### DOCX 原生墨迹与设置

笔迹属于PM根属性及段落锚定，逐笔操作和正文共用事务/history；不能另存React文档历史。Overlay在doc-zoom内按实际段落/物理列几何定位，手势冻结版本，滚动/缩放/外部写取消未完成笔迹。首次聚焦必须preventScroll，避免浏览器自动滚动取消首笔。未知/opaque/共享原资源禁写，复杂表格墨迹暂不显示时须在正文状态明确告知保留与禁用，不能显示「可编辑」计数。

设置沿320px Inspector两组两列，数字输入与px单位在同一flex字段内可收缩，body内滚、动作固定。窄屏从具名折叠菜单打开Inspector时先关闭该菜单，避免遮标题；Escape只关闭最近一层并回live入口/折叠组/当前可见tab。真实浏览器须验证Canvas PNG非空、150%笔宽归一、保存重开及撤销重做；组件Canvas mock不能替代像素证据。

### DOCX 视图与原生表格缩放

打印/Web/阅读、缩放与标题导航属于会话呈现，不改变正文JSON、版本、dirty或历史；唯一EditorContent保持挂载。Web必须关闭并清理实际分页/多栏/页眉脚装饰，回打印重新测量。分页测量同步将`.doc-zoom`归1并finally还原；fit按实际正文滚动区扣停靠Inspector，窄屏覆盖层不冒充剩余正文宽。阅读关闭直接键入，显式Agent写/草稿/整轮回退先退出并提示，CtrlF退出并聚焦可见查找；阅读不是原件保护；导航与定位不写文档，显式应用标题层级才进入正常编辑事务。

标题大纲复用文档导航Inspector，正文完整可见、唯一EditorContent保持。按当前resolvedStyles列出直属普通/显式大纲/样式/编号标题，保留原始空白并用段落位置区分重复或空标题，尊重样式headingOutlineOff。编辑标题回原位置输入，不用纯文本覆盖富标题；≤800px先关覆盖Inspector且焦点留主编辑器。普通标题层级0–9仅接受原件真实样式，显式outlineOnly沿setOutlineLevel；编号或含修订/特殊内联的层级禁用并说明原因。每次选择冻结文档/session/editor/handle/version/保护epoch/position/node；人工编辑及undo使旧目标失效，纯选区不改目标。执行前主动检查保护，走同一Agent单事务及独立history边界，无变化不dirty或增版本；320px内滚、固定单一应用footer，深层缩进封顶。

PM列宽拖拽的clientX差需按CSSzoom转换，命中坐标保持真实屏幕值。cell.colwidth更新后，自有表格extension在同一事务链同步适用的widthPx/colWidthsPct，否则vendor renderHTML仍使用旧表宽/colgroup，模型变化但实际画面不变。固定绝对宽表保存同步tblGrid和tblW；不要为修固定表强制改变原件window/contents/百分比AutoFit或浮动坐标。必需回归含150%真实手势、视觉增宽、下载原生宽度、单步undo及无操作导出精确。

### PDF 本地临时 OCR

显式识别只供当前打开会话复制与查找，不写 PDF、知识库、保存基线、dirty、版本或 history；关闭文档或换源销毁 worker 与临时文字。原生文字索引仍是 PDFium 原文编辑、段落、标注与涂黑的唯一文字目标来源，OCR 不进入这些可写身份或 Agent 的 `read_pages`。结果绑定不可变源字节与来源页，调序、导入及旋转按真实来源重投影；真实字/词框经同次 PDF.js viewport 四角转换，不按字符串长度估算字宽。纸面复制按选区端点对应的原文字偏移提取逻辑片段；不能直接使用 SVG 的 selection.toString()，其逐字元素会被浏览器插入虚假换行。

采用同源固定版本 Tesseract worker、LSTM WASM 与 eng/chi_sim 语言资产；浏览器与 Desktop 共用 renderer preset 复制及许可，路径遵循 BASE_URL，无默认 CDN 或文档文字缓存。初始化和识别阶段均须真实终止底层 worker、结算挂起 promise；迟到结果不能复活。单 worker 串行，每次最多50页/10分钟/100,000字符，单页120秒、最长边2048与4,194,304像素。原生文字、空白识别结果与已识别来源计跳过，不将空白页计入可用结果。

OCR 沿320px Inspector完整高度链，body内部滚动、单一底部开始/重试/停止动作，长错误独立有界滚动。识别范围用有名称的Radio组且各选项保持独立label。进入纸面选字或关闭入口必须先停止扫描并保留已完成结果；选字层聚焦时preventScroll，Escape退出并回可见入口，不能隐藏运行中的唯一停止控件。识别结果、复制/搜索、窄屏420×500与真实本地WASM/静态资产另作浏览器验收，组件Canvas mock不代表浏览器通过。

### PDF 涂黑副本与焦点

涂黑区域仅为临时画布草稿，按真实PDF.js viewport做四Rotate/offsetCrop坐标换算；只在干净且无待提交页面/文字修改时进入。通过私有`redact_copy`导出同version、唯一规范outputs，不发布工作bytes、不改库/dirty/history。导出冻结源/布局/句柄/版本/区域，保存、页切换、工具与源变化取消，失败保留区域；关闭清除草稿不允许身份A→B→A复活。宿主真移除和结构拒绝见shared PDF合同§13，普通绘图覆盖不等于涂黑。

PDF Inspector关闭优先回原live触发器或当前具名组；若用户已转移焦点不抢焦。跨工具分类使来源section卸载时，末级可回开启时捕获且仍连接的可见tab；来源section尚在、操作busy时必须保留原有请求结束后延迟回入口，不能提前回tab破坏该机制。

从PDF具名折叠菜单打开表单/批注等Inspector时，复用`collapsedContent(close)`先关闭菜单，避免覆盖标题。表单的滚动content与固定footer须为panel的同级子项，应用动作和状态不能嵌入滚动body；切换字段保留选择器DOM/键盘焦点，仅重置对应字段草稿。签名显式“放在页面中央”在布局后将实际草稿box滚动到纸面可见中央，手动放置/拖动不自动滚动；actions说明文字样式须限定到说明元素，不能覆盖组件库按钮的内部span。

### PPTX 图片填充与来源预览

图片填充Inspector内使用独立body滚动与固定单一应用footer，不能让选图预览把应用动作挤出420px可视区。预览按真实比例显示，文件读取/解码期间不可应用；格式或编码不支持时给具体原因，保留重新选择路径，不发布旧预览或制造dirty。源文件字节与仅显示转换的图片分开，TIFF最大安全页显示与动画转静态PNG的说明须准确；具体来源编码/资源预算见engine合同。

图表、文本框、页面与节、水印、批注、脚注/尾注和样式管理使用右侧 320px Inspector；编辑容器小于 800px 时覆盖显示，保留至少 32px 文档上下文。面板内部滚动，标题/关闭/Escape/焦点返回完整；长样式表单主动作保持底部可达。Inspector 按解析会话身份隔离，打开时冻结选区及版本，重渲染可更新原件外结构参数但不得绕过过期校验。纯工具栏测试宿主可用紧凑弹层。

### DOCX 当前副本导出

“视图 → 导出副本”物化当前正文和附加保存参数为DOCX，包含未保存的主题/列表/引用/页眉脚/批注/脚注。它与知识库保存使用同一session.save输入，不调用io.save或markSaved，也不清dirty/历史。点击冻结版本和完整参数，重复提交互斥；构建期间变更文档/句柄/版本或新增未定AI草稿时拒绝迟到下载。头部“下载原件”仍按已保存文件下载。

### DOCX 本地对比与只读拆分

对比通过同一 PM 提取器读取当前未保存正文及本地 DOCX，保留空段、重复文字、硬换行和普通表格行/格/段落边界；未知对象和嵌套表格明确排除，不能读取旧 preview 代替活内容。解析前限制压缩与累计解压预算，LCS 分配前限制块数乘积；超限拒绝，不截断比较。结果是只读文字清单，不是 Word 合并修订。文件重选、关闭、编辑及来源会话变化单调废弃旧请求，编辑后 Undo 不使旧结果复活；失败保留文件供重试。

拆分保留唯一主 EditorContent 和原滚动容器，以独立滚动的连续只读副本呈现活正文。副本仅用本地白名单 AST 构造 React 节点和逐项验证的标量 CSS；禁止克隆分页 HTML、传播原 attrs/id、链接、交互或外部资源。直接字符格式、标题、列表及普通表格可预览，复杂对象和完整样式级联不作保真承诺；所有正文类型均须保留原有空白。两类视图均不写正文、保存基线、dirty、版本或 history；关闭回可见入口、折叠组或当前分类。

拆分列表标记须使用主编辑器当前原生编号定义和同一文档顺序的 `computeListMarkerInfos`，包含起始覆盖、多级格式、表格内列表和受保护段落计数；不能按各个 `<ol>` 从1重新生成。只将有界 `marker.text` 作为 React 文本显示，不传播图片标记 URL、字体或原 CSS。缺少定义、图片标记或过长标记时抑制浏览器默认编号并告知未显示，保留原件和列表正文。
