## 局部视觉合同

批准稿明确的小字号及颜色角色可在搜索模块使用具名局部 token，集中导出并由
`createStyles` 消费。这是此批准界面的窄范围例外；不要修改全局 `FONT_SIZE`、
主题色、字号守卫或其他模块，也不要在各组件散落外观判断。

- 输入 14/21，标题 13/20，片段 12/19，分组 11，路径 10/16，快捷键 10px。
- 620px 面板、6px 圆角，桌面输入区 16px 18px / gap10，列表 padding8 / max440。
- 命中顶部对齐、图标宽26、最小高88；详情按钮位于右下角。
- 浅/深辅助区 `#f7f9f8` / `#242629`；hover `#f4f5f5` / `#303337`；
  selected `#eff0f0` / `#34383c`；字段边框 `#e7e9e8` / `#454b47`。
- 浮层使用 `colorBgContainer`；阴影浅 `0 12px 32px rgba(0,0,0,.16)`，
  深 `0 16px 40px rgba(0,0,0,.36)`。与主题相同的文本、焦点、错误角色继续消费主题 token。
- 输入框本身无描边、阴影或圆角焦点环；焦点是整个输入区底部 1px 线。
- 完整信息是独立 480px 详情层；返回时保留查询、选择和搜索焦点。
  名称/移动/查找宿主弹窗为 480px / padding24，含当前文档上下文。
- 命中计数在列表分组标题；AI 区左为图标与预填说明，右为显式交接动作。
- 创建 pending/error 为滚动列表外独立反馈；请求 loading/empty/error 为列表内中心反馈。

例：`font-size: ${SEARCH_TYPE.compact}px`，避免裸写字号或静默替换成相近全局档位。

## 验收合同

功能回归不能证明视觉还原。每次还原须对照冻结源码并保存批准稿与实际产品的同状态截图，
记录计算样式与真实数据差异。至少覆盖浅/深桌面、390px、低高度、详情层、
加载/空/失败，以及重命名/移动/查找弹窗；逐组核对其余交互。

检查焦点底线、字号行高、padding、选中色、图标、路径、详情入口、AI 区和底部快捷键。
窄屏触点至少44px；输入和底部动作保持可达，结果列表内部滚动。
批准稿中的模拟请求不替代真实权限、迟到响应、保存保护及宿主定位回归。

错误例：只确认按钮可用和测试通过就宣称完全还原。
正确例：记录16组差异表，实际浏览器截图与计算样式对照，明确仍未核验的宿主边界。

## AI 操作区的状态几何

AntD 6 的 link Button 在 `:not(:disabled):not(.ant-btn-disabled):hover` /
`:active` 会重新声明 `border` 简写。仅在默认态用 `&& { border: 0 }`
不能保证悬停后仍无边框；实测会让按钮宽高各增加2px、整条AI区增高2px，
文字随之左移/下移。局部状态选择器必须实际赢过组件规则，不能通过全局覆盖修补。

左右图文组使用 flex 居中及明确行高；子图标不缩放、不依赖行内 baseline。
交互过渡只覆盖颜色/背景等绘制属性，避免 `transition: all` 把错误的尺寸变化变成抖动。
保留 focus-visible 和窄屏44px点击区。

实际浏览器须采样 default → hover → leave，以及键盘 focus 状态：
AI行、按钮、文字及图标的 x/y/width/height 保持不变；两组内部图标与文字的
中心线差不超过0.5px。浅深外观与390px均须核对。DOM事件测试或静态截图无法证明
浏览器伪类的最终级联正确，不能替代真实hover的计算样式与尺寸证据。
