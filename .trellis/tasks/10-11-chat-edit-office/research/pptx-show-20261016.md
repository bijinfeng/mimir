## 实现

- `pptx-show.ts`：公开 `PptxShowRequest`、`PptxRehearsalResult`；播放顺序、路径映射、受限本地列表反序列化、真实时钟累计、整秒 native advance ops。
- `PptxShowControls.tsx` / `pptx-show-controls.css`：右 Inspector 持久编辑；具名列表新建/覆盖改名/删除/重排/播放，显示页码与真实标题。按文稿 ID 保存在当前浏览器；存储失败诚实说明仅本次可用。使用 slide.path 避免正常重排后指错页，删除页过滤。对隐藏页遵循固定上游：起始隐藏页可播放，其余隐藏页跳过。
- Inspector 主动作在固定底部，内部滚动；页码+标题第二行截断，完整标题 title 提示，操作区不压缩；极窄行可换行。沿 shell/Antd 既有原语与主题 token。
- `PptxPresentation.tsx` / `pptx-presentation.css`：指定子集播放、原页号及子集进度、最后一步结束排练、结束按钮/Escape 录末页；重复访问累计真实 `performance.now()` 停留，计时显示本页和总计。排练禁用原件自动换片，以用户动作测量；纯放映不写文档。结果仅在版本仍等于起始版本时发布；关闭卸载清定时器并回焦。
- 排练结果列出各页及总计，“应用计时”/“丢弃”明确选择；未访问页不改。应用为一次 `apply(ops[])`，每页 setAdvanceTime，整秒、至少一秒、unsignedInt 上限；root 的 applyPanelOps 保证一次 atomic 与历史。版本/页路径变动拒用旧结果；重复提交、pending、卸载/切文档后的迟到 UI 结果均有保护。

## 根会话整合合同

```ts
PptxShowControls({ documentId, slides, version, pending?, rehearsal,
  onDismissRehearsal, onStart, apply })
// onStart request: { start, slideIndices?, rehearse?, presenter? }
PptxPresentation({ session, start, presenter, slideIndices?, rehearse?,
  onRehearsal?, onClose, triggerRef })
// result: { version, slidePaths, perPageMs }
```

收到 onRehearsal 后保留结果并打开“自定义放映与排练”Inspector；apply 使用当前画布的 `applyPanelOps`。入口区从头/当前、演讲者从头/当前由 root 接线，pending 时禁用。各入口应传真实/指定触发器 ref，不能把上次仍聚焦的不同按钮误认为本次来源。
