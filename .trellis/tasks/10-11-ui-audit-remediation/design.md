## 按数据与界面边界实施

### 保存与编辑（F1、F2、F13、F17）

- 自动保存的 Markdown 笔记不再承诺“丢弃已保存的改动”。离开守卫对它提供“保存并离开／继续编辑”，保存请求仍在途时等待完成；失败不导航。其他显式保存编辑器保留现有三选项。无需为本轮建立跨版本回滚协议。
- 快捷键标签由平台判断统一生成；不改变现有键盘绑定。
- 两条新建笔记路径传一次性焦点意图，待编辑器就绪才聚焦正文；打开已有笔记不抢焦点。
- 内链存储为稳定文档 ID 的 Markdown URL `[标题](/doc/<id>)`，兼容现有反链解析。`[[` 补全只查已有笔记，选择后替换输入片段；编辑器链接点击经应用导航与未保存守卫。不存在的笔记本轮不自动创建。

### 导航与搜索（F3、F7–F9、F14–F16、F18）

- 账号 Dropdown 父子状态受控，并在路由变化、Esc、外点击统一收起。浮层关闭集中恢复到连接中的触发控件，卸载时送到当前视图可见主入口。
- 600px 侧栏作为模态覆盖层，背景 `inert`，Esc/关闭按钮恢复焦点；触屏卡片“更多”常显。
- 使用每账号、每浏览器的有限 MRU 文档 ID 列表作为最近打开来源。空搜索展示 MRU，现有侧栏加入轻量“最近笔记”切换，不新建永久文件树、额外内容列或伪标签页。已删除/不可访问 ID 过滤；编辑页切换仍经未保存守卫。
- 全局入口扩展上下文命令（重命名、移动、搜索当前笔记、返回知识库），保留一个输入框，但将 AI 提问显示为明确可选的一行；“没有文档匹配”与“没有命令匹配”分别说明，不暗中把 Enter 变成提问。
- 递归文件列表保留，行内显示相对目录路径，当前目录面包屑强化；移动完成提示目标及撤销按钮，撤销通过同一个更新 API 还原旧目录。

### 设置、计数与文案（F4–F6、F10–F12、F19）

- URL 校验在前端反馈到字段旁，服务端原因原样保留，草稿不清除。供应商表单错误集中管理输入关联与首次错误聚焦。
- 账号与 S3 草稿保持在设置页会话级内存中，折叠或切分区不清除；密钥不存 localStorage。服务端更新后只同步未修改字段。
- S3 控件以 `entry.label` 提供稳定可访问名称，包括 Switch。
- 分块统计与待嵌入计数只统计未软删除文档；SQLite 与 Postgres 查询语义一致。
- 问 AI 范围和移入回收站文案准确描述现有行为，不许暗示不存在的一键恢复功能。

## 与现行产品决策的关系

`.trellis/spec/project/product.md` 的两栏工作区和知识库内目录浏览继续生效；F14 采用最近笔记入口而非第三栏文件树。Markdown 自动保存的离开动作需要更新 §5.9，使可见选择真实反映能否丢弃；Office 显式保存的三选项保留。F15–F17 增加的最近记录、命令和内链行为同步写入产品规范。

## 验证策略

单元/组件测试覆盖竞态、错误关联、MRU 与命令选择、内链序列化、软删除计数和目录撤销。浏览器实测覆盖报告中的复现路径、键盘焦点、浅深主题与 600px。真实触屏及屏幕阅读器若不可用，明确留为设备验收，不把模拟结果称为已实测。
