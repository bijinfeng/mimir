# 设计：文档 Agent 共用接缝

将当前 DOCX 专属的数据流抽成按格式判别的 `DocumentAgent`，不改 TanStack AI 作为唯一模型工具循环的决定。共享层只负责文档身份、工具目录、版本、执行结果、续轮与历史；编辑语义仍由格式包所有。

- `packages/shared` 定义格式联合、能力响应、工具结果和运行时 schema。DOCX 旧字段/事件作为兼容输入处理；新请求带 `format`、`documentId`、`roundId`、`version`、冻结的格式上下文。
- 服务端在每次新轮和续轮核对文档、用户、格式、会话及工具白名单。中断记录带格式；SQLite/PostgreSQL 同步迁移。重复或过期消费拒绝，不重放工具。
- `packages/chat` 的桥接层只依赖通用句柄，格式附加能力（修订、媒体、写作草稿）以明确可选接口暴露。桥在执行前后检查文档与版本；工具失败的 `ok: false` 确实进入续轮。
- Renderer 对笔记与五种文件挂载当前句柄；卸载或切文档清掉句柄。能力状态按格式与服务配置查询，旧 DOCX 提示和历史继续可见。
- 对外搜索、图片生成、媒体分析、`create_document` 的服务适配按功能复用；配置仍在通用“模型”“网络搜索”。

本子任务不实现五格式具体编辑操作。可用工具目录由各格式后续注册；没有执行器时不宣传该格式已经可写。
