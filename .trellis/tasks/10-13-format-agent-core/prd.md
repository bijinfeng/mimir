# 多格式 Agent 共用通道

## Goal

将 DOCX 专属工具循环、能力查询和画布句柄改造为按格式隔离的共用接缝

## Requirements

- 复用 TanStack AI 工具循环、AG-UI 历史与受控客户端工具续轮；按已鉴权的当前文档类型注册工具，不接受请求自行添加写工具。
- 编辑器提供身份、版本、冻结选区、执行、回退与销毁合同；格式独有参数留在各格式执行层。
- 工具结果和失败准确进入模型续轮；停止、切文档、后续人工修改时旧工具不能落地。
- 能力状态按格式显示，复用已有通用模型、网络搜索及媒体服务设置。

## Acceptance criteria

- [ ] 五种格式仅对当前文档提供各自工具；库级会话无写权限。
- [ ] 一次中断只消费一次；版本冲突、停止及切文档不误写，错误进入模型续轮。
- [ ] DOCX 原有问答、工具、修订、回退、保存与历史回归通过。

## Dependency

本子任务先于五格式执行层；上游清单见父任务的 `research/genoffice-five-format-inventory.md`。目标运行环境由父任务规划决策确定。
