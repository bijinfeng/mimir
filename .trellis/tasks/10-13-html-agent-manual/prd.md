# HTML Agent 与手动编辑对齐 GenOffice

## Goal

接入固定版本 GenOffice HTML 元素操作与对应手动编辑能力

## Requirements

- 逐项对照上游 6 个 Agent 工具、13 种 `HtmlOp` 及手动命令，覆盖源码/大纲读取、文本、元素、属性、样式、移动与页面写作。
- 批量操作按同一基线验证并原子落地；源码编辑、预览元素选择与 Agent 使用同一文档版本。
- 保存保留 BOM/换行风格，预览注入属性不写入原件；页面生成或外部资源失败时真实报告。

## Acceptance criteria

- [ ] 能力矩阵逐项记录上游、Mimir 入口与实际执行验证；所有目标能力通过后才完成本子任务，Agent 与手动元素编辑结果一致。
- [ ] 代表性元素、样式和整页写作在画布/预览可见，保存重开与源码一致。
- [ ] 原子批处理、版本冲突、预览隔离与原件保真回归通过。

## Dependency

依赖 `10-13-format-agent-core`；复用已有 GenOffice HTML 解析映射与补丁原语。
