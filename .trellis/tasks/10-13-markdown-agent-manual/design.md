# 设计：Markdown Agent 与手动编辑

继续用 Mimir 笔记的 Tiptap 文档与正文列作为唯一真相；上传 `.md` 仍导入笔记。固定上游的 8 个 Agent 工具及 `editor/ops.ts` 15 种操作按 Mimir 方言映射，块索引和选择在发送时冻结。操作在一个编辑器事务/明确的批次边界中执行，更新同一 dirty、撤销与保存状态。上游的图片、frontmatter 和长文写作能力使用现有通用服务及笔记媒体上传通路；图片 URL 不绕过服务端安全抓取。手动命令以当前紧凑工具栏和上下文菜单承载，并补齐上游命令矩阵中缺的操作。保存后正文、vault 文件与索引一致；不增加第二个 Markdown 原件编辑器。

兼容边界：Mimir 已有内链、Markdown 方言和笔记标题/保存逻辑，扩展操作不得把这些结构降级为纯文本替换。因手动与 Agent 共用活文档，整轮回退必须验证其后用户编辑版本。
