# 实施计划：PDF Agent 与手动编辑

1. [ ] 建立 45 工具、26 内部操作（8 种 `apply_ops` 可调用）及上游手动命令矩阵，标出 PDFium/字体/OCR/图像/原生依赖与各工具验证夹具。
2. [ ] 先打通两端可用的 PDF 宿主会话、资源打包、版本、撤销、真实字节保存与失效清理；没有此门槛不得注册文字/图片写工具。
3. [ ] 依序接文字读取与编辑、批注/回复、图片、表单、页面/文档结构及新文件工具；手动和 Agent 使用同一叠层与执行器。
4. [ ] 对普通文字、中文字体、扫描件、批注线程、图像、表单、签名/未知 Catalog 文件逐类检查可执行或明确拒绝；停止、切文档和并发人工改动不误写。
5. [ ] 保存并用 pdf.js、pdf-lib 与独立阅读器交叉验证文字位置、页面、批注和表单；保存两次无回滚，原件不能安全处理时保持 dirty/原件不变。
6. [ ] 跑 Office/server/renderer 测试、`pnpm check`、目标宿主构建及浏览器/桌面实测；有第三方配置的工具单独做真实调用。

风险：PDFium WASM/原生资产、字体授权与字形布局、OCR 误识别、签名失效及整体重建丢失未知对象；不能以按钮或模拟结果代替独立读回。
