# PDF Agent 与手动编辑对齐 GenOffice

## Goal

接入固定版本 GenOffice PDF 内容、批注、图片及页面操作与对应手动编辑能力

## Requirements

- 逐项对照上游 45 个 Agent 工具、26 种内部操作（8 种可由 `apply_ops` 调用）及手动命令；模型只调用上游标注可用的操作。
- 引入内容文字、批注、图片、表单与页面编辑的真实写入能力；OCR、字体、PDFium/主进程依赖按目标运行环境适配。
- 画布与页面结构版本、脏状态、回退和保存一致；未知目录结构或无法安全保留的原件拒绝写回并说明原因。

## Acceptance criteria

- [ ] 能力矩阵逐项记录上游、Mimir 入口与实际执行验证；所有目标能力通过后才完成本子任务。
- [ ] 代表性文字、批注、图片、表单和页面操作可由 Agent 与手动入口分别执行，保存后独立阅读器重开正确。
- [ ] 扫描件、复杂 PDF、切文档、停止、版本冲突及失败回退回归通过。

## Dependency

依赖 `10-13-format-agent-core`；需先按父任务决策完成目标运行环境适配，再开放相应工具。
