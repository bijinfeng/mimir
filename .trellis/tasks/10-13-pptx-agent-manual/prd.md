# PPTX Agent 与手动编辑对齐 GenOffice

## Goal

接入固定版本 GenOffice PPTX 幻灯片操作与对应手动编辑能力

## Requirements

- 逐项对照上游 17 个 Agent 工具、71 种 `pptx-ops` 操作（61 种模型可调用）及手动命令；读取未保存页、元素和冻结选区。
- 文字、形状、媒体、图表、表格、幻灯片/母版、动画与 deck 级操作在画布可见并保存重开；保留多 run 与未知 OOXML 结构。
- 生成幻灯片和外部搜索/媒体工具复用通用服务，失败或配置缺失时准确报告。

## Acceptance criteria

- [ ] 完整能力矩阵逐项记录上游、Mimir 入口与实际执行验证；所有目标能力通过后才完成本子任务。
- [ ] 代表性文字、对象、图表/表格、动画与幻灯片结构可由 Agent 和手动入口分别修改，保存重开正确。
- [ ] 未保存画布、版本冲突、失败/回退及原件保真回归通过。

## Dependency

依赖 `10-13-format-agent-core` 及父任务确定的运行环境。
