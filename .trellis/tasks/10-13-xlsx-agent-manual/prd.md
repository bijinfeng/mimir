# XLSX Agent 与手动编辑对齐 GenOffice

## Goal

接入固定版本 GenOffice XLSX 工作簿操作与对应手动编辑能力

## Requirements

- 逐项对照上游 13 个 Agent 工具、55 种工作簿 DSL 操作及手动命令；读取未保存状态与冻结的工作表/范围选择。
- 公式、格式、行列与工作表结构、图表、表格、透视、数据验证等须真实执行并保存；不静默丢失原件结构。
- Agent 与手动操作经同一计划/应用和撤销路径；部分失败、公式重算、超大工作表限制如实反馈。

## Acceptance criteria

- [ ] 完整能力矩阵逐项记录上游、Mimir 入口与实际执行验证；所有目标能力通过后才完成本子任务。
- [ ] 代表性公式、格式、结构、图表与数据能力可由 Agent 和手动入口分别修改，保存重开正确。
- [ ] 未保存画布、版本冲突、失败/回退及复杂原件保真回归通过。

## Dependency

依赖 `10-13-format-agent-core`；目标运行环境由父任务规划决策确定。
