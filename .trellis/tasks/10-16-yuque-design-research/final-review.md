# 最终规划复核：Mimir 语雀风格整体改版

日期：2026-10-17。用户已明确指示“开始实施”，本摘要完整范围已批准，进入实施。

## 目标

把已确认的白灰表面、中性导航、绿色主操作与宽松正文排版落到 Mimir，形成覆盖 Web / Desktop 的共享设计系统，让知识内容和当前工作成为视觉中心。

## 实施范围

- 浅深主题、基础组件、字体角色、边框 / 圆角及 hover / pressed / focus / disabled / loading / error 状态。
- 约256px统一左栏、约52px紧凑入口、窄屏导航覆盖层；知识库与文档布局、设置通用表单。
- Chat主视图 / 文档侧栏、Office共用工具区 / 菜单 / 缩略图、Desktop标题栏 / 首启 / 加载底色继承新主题。
- 正式设计文档、包级spec及相关测试契约同步，保持共享provider与现有主题桥。

## 不在范围内

不改API、数据库、认证、Agent业务协议或文件格式；不新增团队协作、分享、独立仪表盘、阅读 / 编辑模式切换。不改变用户现有卡片 / 列表与折叠偏好，不批量替换文档内容颜色。

## 关键决定

- 用户认可的浅色稿作为视觉方向；深色采用同布局的中性深灰适配，绿色用于操作与真实状态，导航选中保持中性。
- 6px控件圆角；UI约14px与阅读约15px分开，正文以760px宽度起步。
- 主按钮计划 `#00834d` 白字，纯色对比约4.82:1；元信息浅色校准为 `#6b6b6b`，保证在常用选中底上达到4.5:1目标。
- 保留统一880px窄屏断点，设置切Select、文档隐藏右大纲、工具条局部适配、导航覆盖打开并可关闭 / 恢复焦点。
- 单一共享主题provider；导航灰色选中与品牌语义浅底拆开，Office沿用现有桥，不额外套主题。

- Office有旧变量fallback，导航有本地强覆盖，启动底色有硬编码；逐项处理，不做全仓颜色替换。
