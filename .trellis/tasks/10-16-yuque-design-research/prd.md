# 语雀设计调研与 Mimir 主题改版

## 目标与用户价值

把用户已认可的语雀风格适配到 Mimir，形成统一、安静、突出知识内容的视觉系统。研究与完整规划已获用户明确批准，2026-10-17 按“开始实施”进入产品落地与验收。

## 背景与确认

- 2026-10-16 用户同意创建 Trellis 任务并进入规划。
- 2026-10-17 用户选择整体迁移主题、基础组件、左导航、知识库与文档布局；随后批准制作三张代表稿。
- 用户已明确认可知识库、文档、设置三张浅色稿：“非常 nice，我很喜欢，继续”。本轮补深色与窄屏关键状态，收敛最终实施方案。
- Mimir 为单用户、自托管的知识工作区；共享 UI 在 packages/renderer，覆盖 Web 与 Desktop，并向 Chat / Office 提供主题。
- 本次明确以语雀公开界面为视觉首要参考；既有 Obsidian 参考作为布局对照。Office 工具能力继续以 Office 网页版 / Google Docs / GenOffice 与现有实现为准。

## 需求

| ID | 范围与行为 |
| --- | --- |
| R1 | 共享浅深主题、基础组件与状态；白灰 / 中性深灰表面、绿色主操作、中性导航选中，6px 控件圆角。UI 约14px与阅读约15px为独立文字角色 |
| R2 | 展开态整合为约256px单一左侧栏，保留搜索、知识库、新建对话、收集、目录树、历史对话、最近笔记、账号 / 设置；保留约52px紧凑态与折叠偏好，窄屏提供可关闭导航覆盖层 |
| R3 | 知识库按信息、操作、文档建立层级；保留列表 / 卡片及用户偏好、复制库ID、上传 / 拖放、文件夹归属、创建文件与文件夹、处理 / 失败状态；不恢复已退役的全部文档路由 |
| R4 | 文档采用目录 / 正文 / 大纲或AI的工作区，正文宽度约760px起步；保留笔记直接编辑、各格式工具、保存反馈、未保存保护、文档 / 全局AI范围、引用回原文；不复制重复标题 |
| R5 | Chat主视图与文档侧栏、Office外壳 / Ribbon / 缩略图 / 菜单、Desktop标题栏 / 首启 / 加载底色同步主题；不改变内容颜色和命令能力 |
| R6 | 沿用880px统一窄屏断点；窄屏设置分区用Select、正文隐藏大纲；390px下表单堆叠、网格单列、工具条局部适配，保留关闭与焦点恢复，不以隐藏命令代替适配 |
| R7 | 同步正式设计文档与spec，保留主题继承、真实渲染、对比度与行为质量门；按新契约更新旧蓝色色值断言，不通过删除检查实现改色 |

## 验收标准

| ID | 可观察结果 | 对应需求 |
| --- | --- | --- |
| AC1 | 知识库、文档、设置、Chat与Office在浅深外观下使用同一套中性表面与绿色操作体系，切换主题和首帧无旧蓝底闪现 | R1、R5 |
| AC2 | 展开态只有一条全局左栏，现有入口与目录可达；折叠偏好在窄屏往返后恢复，用户现有数据与视图偏好保持 | R2、R3 |
| AC3 | 列表 / 卡片、上传、创建、库ID复制、当前目录与失败重试行为可用；长标题和状态不挤掉主要动作 | R3 |
| AC4 | 笔记可直接编辑并保存；Office各格式既有命令可用；大纲、AI范围与引用回原文保持语义，离开未保存内容受到现有保护 | R4、R5 |
| AC5 | 390px、879 / 880 / 881px与宽屏无页面横向溢出；工具局部滚动和内容滚动可用，表单输入及提交可达 | R6 |
| AC6 | 窄屏导航X / 遮罩 / Escape可关闭，焦点进入并返回触发点，关闭后无残留滚动锁；键盘焦点和选中状态清楚 | R2、R6 |
| AC7 | 普通文字目标≥4.5:1、正文保留≥7:1质量门、关键焦点与控件边界目标≥3:1；状态同时使用文字 / 图标，用户文档颜色不被全局反转 | R1、R4、R6 |
| AC8 | Web与Desktop、主Chat与文档Chat、共享Office外壳通过针对性检查和pnpm check；真实运行截图与已批准设计方向一致 | R5、R7 |
| AC9 | 研究证据区分采样 / 推断 / Mimir建议，正式设计文档与实现保持一致；无团队协作或其他额外产品能力混入本次改版 | R7 |

## 不在范围内

不改 API、数据库、认证、Agent业务协议、文件格式或编辑器命令；不新增团队协作、分享发布、独立仪表盘、阅读 / 编辑模式切换；不迁移文档内容色，不更改列表 / 卡片默认偏好。不要求复制无法访问的语雀登录态页面。
