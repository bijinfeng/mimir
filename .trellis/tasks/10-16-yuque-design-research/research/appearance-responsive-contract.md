- 语雀的公开知识库 / 阅读页实测见 `yuque-design-study.md`；登录态工作台、实际编辑器、深色模式缺直接证据。深色与窄屏是基于已确认视觉语言的 Mimir 适配设计。
- 本任务已检查 WeKnora 官网及公开源码，版本 **v0.8.3**、SHA **3e22822c1d2397be730c458c7539d0eb8c113a24**，版本与源码证据见 `weknora-release.json`、`weknora-source-index.json`、`weknora-theme.css`。其浅深主题的角色组织适用，鲜绿白字对比不足，不直接复制。知识库 / Agent 的来源与原文定位语义可参考，Office 工具栏不参考其 Markdown 编辑器。
- 导航 / 设置 / 大纲共享窄屏事实来自 `packages/renderer/src/lib/nav-collapse.ts`；断点由 `packages/renderer/src/theme/tokens.ts` 的 `NAV_NARROW_BREAKPOINT = 880` 提供，继续保持单一来源。
- 保留现有共享主题 provider、Chat 宿主继承、Office `--me-*` 桥，详细消费链与具体文件行号见 `migration-code-map.md`。

## 颜色角色

| 角色 | 浅色 | 深色 |
| --- | --- | --- |
| 主内容表面 | `#ffffff` | `#18191a` |
| 侧栏 / 辅助背景 | `#f7f8f8` | `#1f2022` |
| 卡片 / 输入表面 | `#ffffff` | `#202225` |
| 导航选中底 | `#eff0f0` | `#303235` |
| 主文字 | `#262626` | `#eceeef` |
| 次文字 | `#595959` | `#b3b6bb` |
| 元信息文字 | `#6b6b6b` | `#969ba2` |
| 白字主按钮底 | `#00834d` | `#00834d` |
| 链接 / 成功文字 | `#007a45` | `#6bdaa5` |
| 装饰性分隔线 | `#e8e8e8` | `#3b3e43` |
| 输入框 / 未选复选框边界 | `#8a8a8a` | `#686e76` |
| 错误文字 | `#b42318` | `#ffb4ab` |
| 警告文字 | `#8a5700` | `#f3c46d` |

元信息从浅色稿候选 `#737373` 校准到 `#6b6b6b`：前者在选中灰底约 4.15:1，后者在白 / 辅助 / 选中三种底上的最低值约 4.67:1。此项是可读性校准，保持中性灰视觉。原始静态稿不应当作为逐像素 token 契约。

用 WCAG sRGB 相对亮度计算的计划值见 `planned-contrast.json`：主按钮白字约 4.82:1；hover 底 `#007846` 约 5.56:1，pressed 底 `#006b3e` 约 6.62:1。深色元信息在四种常用表面最低约 4.60:1，深色输入边界在三种表面最低约 3.10:1。这是纯色计划值计算，不是对运行中页面或整张截图的 WCAG 合规结论；Ant Design 校准后的实际 CSS 值仍需测量。

## 交互状态

| 控件 / 状态 | 约定 |
| --- | --- |
| 导航默认 / 当前 | 中性图标与文字；当前用灰底、600–700 字重与 `aria-current` 表达。树的父位置与当前文档仍有层级差别 |
| 导航 hover | 采用中性表面变化，hover 不产生持久选中；当前项继续以字重和语义区别 |
| 品牌按钮 | 默认 / hover / pressed 按上面的三档深绿；loading 保持尺寸与明确状态，disabled 不能点击或触发提交 |
| 键盘焦点 | 2px 可见焦点环、与边界留 2px 距离；浅色用 `#00834d`，深色用 `#6bdaa5`。不得用清除 outline 实现外观统一 |
| 输入与错误 | 有标签、边界和焦点；错误同时显示文本与错误状态，避免只靠红色；真实提交 / 清除密钥行为保持现状 |
| 用途选择 / 编辑器按下态 | 与导航选中分开：保留绿色语义浅底及文字、`aria-pressed` / `aria-selected`。不能把全局 `colorPrimaryBg` 改灰 |
| 处理 / 对话状态 | 保留上传中、失败重试、运行中、引用定位等真实状态；颜色配合文字 / 图标，不能仅改色丢失状态信息 |
| 保存状态 | 文档沿用现有保存反馈和离开保护；供应商表单仍需“保存 / 取消”，不引入自动保存承诺 |

所有图标沿用现有共享图标映射，同一动作跨页一致；稿中的示意图标不构成新增品牌图标要求。常用控件 6px 圆角；触控区域可达 40–44px，图标本身不需等比例放大。

## 响应式与面板

| 场景 | 行为 |
| --- | --- |
| 宽屏展开 | 约 256px 的单一左侧栏；内容列最小宽度为 0。知识库网格按可用宽度从三列到两列 / 一列，不用固定列最小宽度撑破页面 |
| 宽屏手动折叠 | 约 52px 紧凑入口；用户偏好继续持久化，不因暂时窄屏而覆盖 |
| ≤880px | 同一窄屏事实使导航紧凑、设置分区变 Select、正文隐藏右大纲；由统一 token 提供断点，覆盖 879 / 880 / 881px 临界值 |
| 390px 代表状态 | 52px 紧凑栏 + 338px 内容区；主内容约 16px 内边距，表单标签置于控件上方，控件宽度不超过可用列宽 |
| 展开窄屏导航 | 约 280px 覆盖层，极窄屏限制在视口内；遮罩与 X 可关闭，Escape 可关闭，焦点进入抽屉并在关闭后返回触发点。关闭时背景不保留滚动锁或焦点陷阱 |
| 知识库动作 | “添加文档”为主操作；空间不足时把现有“新建文件 / 新建文件夹”收进“新建”菜单，保留当前目录归属及列表 / 卡片偏好 |
| 文档工具区 | 复用现有 CompactToolbar 折叠与分组策略，允许工具条局部横向滚动；正文不得因此横向溢出，不能隐藏命令代替适配 |
| 文档问 AI | 窄屏不并排塞入正文 / 大纲 / AI；沿用现有面板与返回关闭机制，保持引用回原文和未保存保护 |
| 窄屏设置 | 只展示当前分区，URL 的 `section` 语义不变；字段 / 模型行可堆叠，保存 / 取消在表单尾部，通过正常滚动可达 |

展开 / 关闭导航与文档切换的既有动作优先复用；没有已存在的行为时，仅补本次适配必需的焦点与关闭逻辑，不新增路由或独立仪表盘。

## 实施时验收

- Web 与 Desktop 的浅深外观，以及主 Chat / 文档 Chat、Office 工具区 / 缩略图 / 菜单，均继承统一主题。
- 390px、880px 临界与宽屏无页面横向溢出；内容可滚动，工具和表单操作可达；导航可关闭并恢复焦点。
- 普通 UI 文字对比度目标 ≥4.5:1，正文保持现有 ≥7:1 守卫；焦点 / 关键控件边界目标 ≥3:1。禁用与内容原件按其语义处理，不能以删除可读性测试换色。
- 深色不全局反转用户文档颜色，Office 原件纸张、调色板、正文颜色保留内容语义。
- 真实运行时再核对主题色、输入状态、hover、焦点、保存和未保存保护；静态图与配色计算不替代这些验证。
