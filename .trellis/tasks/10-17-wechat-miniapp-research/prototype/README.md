# Mimir 微信小程序高保真交互原型 v1

日期：2026-10-18。任务仍为 planning；用户要求先看交互，本目录不属于正式小程序实现。

本地预览：http://127.0.0.1:4391/ 。由本会话启动。左侧 10 个场景可以直接进入，窄窗口左下角用场景选择器；右上角保留 iPhone / Pixel 10 预览设备选择。手机内可点击操作、拖动正文滚动，输入时显示模拟键盘。外观从评审侧栏或“我的 → 外观”切换。

## 建议评审路径

1. **问答与来源**：选择范围 → 点击示例问题或自行输入 → 查看分段回答 → 点击引用 → 打开原文 → 问这篇。切换范围另开会话，空库显示没有可用资料。
2. **回答沉淀**：回答下方“存为笔记” → 选择知识库 → 确认 → 查看已存笔记。此处保存仅在当前页面内存中，刷新后还原。
3. **浏览与搜索**：知识库 → 单库文档 → 阅读；“搜索”直接返回示例标题 / 正文中的文字匹配，无命中有空态。按标签可筛选示例资料。
4. **编辑与草稿**：阅读 → 编辑 → 修改 Markdown → 源文 / 预览 → 保存。取消或返回时可继续编辑、保留草稿离开、放弃修改；阅读页有恢复草稿入口。
5. **冲突**：左侧“保存冲突”模拟电脑先保存。手机草稿可另存，或保留后读取电脑版本；不会把旧草稿写回同一笔记。
6. **资料整理**：阅读 → 整理 → 修改标题、标签、所在知识库。网页 / PDF 无正文编辑入口，笔记可追加。
7. **链接收集**：填写 URL → 选择位置 → 收集 → 等待模拟结果 → 查看资料。“抓取失败”场景保留原 URL，重试演示成功路径。
8. **文件与恢复**：“原件查看”是微信文件查看器的边界示意；“中断恢复”显示部分回答及重新提问入口。输入模拟账号可演示登录 / 退出。

## 视觉与交互来源

继承 `.trellis/spec/project/design.md`、`apps/web/DESIGN.md` 的白灰工作面、绿色主操作、系统中文字体、6px 控件圆角，以及原仓库的 `favicon.svg` 标记；Lucide 图标沿用项目图标语法。原型没有更改全局视觉规范或生产组件。

移动阅读 / 编辑的任务分离参考本任务 Obsidian 研究；知识库范围与来源参考 WeKnora v0.8.3 的职责划分，其小程序未实现的预览、编辑和引用不能冒充已复用。具体版本、源码与适用性在 [研究报告](../research/miniapp-product-research.md)。PDF / Office 仅展示打开原件的边界，未新增工具栏设计。

## 演示边界

- React / Vite 是设计原型运行时。正式方案仍是 `apps/miniapp` 原生 TypeScript / WXML / WXSS。
- 数据均为虚构示例。没有调用 Mimir API、模型、微信登录、抓取或文件打开接口；不会改动真实知识库。
- 回答是预设文本，来源范围按当前样例集合限制。输入任意问题不能证明真实检索质量；动画仅演示逐步反馈，不是实际 SSE。
- 草稿、历史、保存、元信息和导入结果在组件内存中模拟；不提供跨刷新或跨设备持久化。不要在原型输入真实敏感资料或密码。
- 本次演示的应用数据与状态在刷新后还原。草稿仅有一个内存槽位；保留草稿后编辑其他笔记或新建，会回到原草稿并提示先保存或放弃，避免静默覆盖。正式产品仍需按实例、账号和文档隔离多份草稿。
- 新建草稿恢复后仍按新笔记保存；草稿目标库独立保存，不随回答存笔记、链接收集或资料整理表单的位置选择改变。
- 登录仅校验项目规定的示例账号 `admin@example.com` / `12345678`（或用户名 `admin`），无真实认证与设备凭证。
- Markdown 预览仅支持本组样例涉及的标题、段落、引用、列表与任务列表；正式实现的表格、代码、双链及高级块处理仍按 PRD 验收。
- 浏览器模拟键盘、iPhone / Pixel 布局通过，不等于微信开发工具、iOS / Android 真机或发布审核通过。

## 文件与运行

应用自有部分：`src/Prototype.tsx`、`src/prototype.css`、`public/mimir.svg`；设备 / 键盘壳由 Product Design 的 mobile-app 模板提供，保留其运行时锁与资产。`verification/` 保存真实浏览器截图和检查记录，`overview.png` 为六屏真实截图拼接的静态概览，没有使用图像生成。验证范围与限制见 [设计验收记录](design-qa.md)。

在本目录执行 `npm ci`，再用 `npm run dev -- --host 127.0.0.1 --port 4391 --strictPort` 重启。`npm run build` 包含 TypeScript 与运行时完整性检查。`node_modules`、`dist` 不提交。没有部署或发布外网。

原型反馈与正式验收分开记录。交互评审后再更新 [PRD](../prd.md)、[设计](../design.md) 与 [实施计划](../implement.md)，重新请求完整方案批准。
