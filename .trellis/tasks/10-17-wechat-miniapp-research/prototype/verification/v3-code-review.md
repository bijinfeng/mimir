# 原型 v3 独立代码审阅

日期：2026-10-18。对象为任务内 React / Vite 交互 mock；正式任务保持 planning。本次只写此报告，没有操作主会话浏览器、修改实现或提交代码。

## Findings (fixed)

- **回答的来源编号会随资料移动改变。** 原实现每次渲染都从当前 `docs` 按回答范围重新计算 `evidence`。在指定知识库生成回答后，从引用打开原文并将它移入另一库，返回时原编号会指向不同资料。审阅反馈后，实现者将来源改为生成回答时的快照，历史与中断场景也通过同一恢复入口装入固定来源；“打开原文”按快照 ID 查找当前文档，保留当前标题和目录，原文不存在时提示而不打开其他文档。已复核最终代码；移库后的实际点击复验由主会话执行。
- **模板全局 `p` 颜色影响深色正文和说明。** 主会话首先发现正文 `#555`，独立审阅补充确认状态提示和退出面板的裸段落同样受影响。最终应用层使用 `.mimir-app :where(p), .sheet-app :where(p)` 继承主题，避免高特异性覆盖后续的元信息语义色；正文显式使用正文 token，固定白纸里的段落保留局部 `#555`。已复核最终选择器和覆盖顺序，未修改受保护模板。

以上修复由实现者及主会话完成；本审阅者未越过文件所有权修改实现。

## Findings (not fixed)

最终补丁复核未发现本轮范围内仍需修复的问题。

## 指定路径核对

- 追加模式只显示目标身份和追加正文；正常保存使用当前文档的 `body` 加追加内容，不回写草稿中可能过时的标题、标签或目录。
- 追加和全文编辑共用单草稿保护，恢复时保留 `draftMode`；尝试编辑其他资料或新建时不会覆盖已有草稿。取消与返回在有改动时进入保留 / 继续 / 放弃路径；放弃会清理模式与基线。空白追加不能保存。
- 追加基线变化或显式冲突状态阻止原文写入；保留并重读仍保留草稿，另存创建新 ID 并保存草稿正文。冲突演示是 mock 状态，不代表真实并发保存已验证。
- 编号引用展示对应一项，“全部来源”显示固定来源列表；来源数量、编号与存为笔记的 Markdown 共用同一快照。单篇范围按 ID 选取来源，无资料时有明确空态，不扩大范围。
- 从回答打开原文记录回答滚动位置；阅读返回后恢复。问答与阅读固定工具栏位于 `MobileScroll` 外。网页、PDF 只有元信息整理与相应只读操作，不暴露正文编辑或追加。
- 品牌 SVG 经应用构建导入为数据 URL；没有更改设备、键盘或滚动运行时。
