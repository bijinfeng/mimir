# AI对话与生成交互精修

## 目标
第七模块延续已认可的语雀风格：让完整对话、输入、生成、检索证据与 Agent 交接更清楚、稳定，交付可操作的 HTML 当前/打磨后对比稿；用户认可本版之前不改产品代码。

## 已确认范围与要求
- R1 根据 packages/chat 及 renderer 对话宿主实际源码盘点所有页面、菜单、消息类型、状态与可恢复路径，使用稳定 ID 和来源锚点。
- R2 覆盖主对话、新建/历史、范围与模型、思考强度、队列、流式消息/工具/引用/媒体、停止/失败/重试、笔记保存及 Agent 中断/截图交接。以源码为准，不新增业务能力。
- R3 每个适用切片覆盖浅深主题、窄屏、键盘、hover/focus/pressed/disabled/loading/empty/error/success/cancel/recovery，缺省状态与原生/接口边界须明确。
- R4 独立 HTML 同场景/内容/尺寸比较，支持导航和真实原型操作；完整覆盖映射不能冒充全部 GUI 实测。
- R5 WeKnora 官网与固定公开源码版本须记录具体证据和适用判断；保持此前已认可视觉规范、模型绑定与 Agent 执行合同。
- R6 冻结版本/哈希、本地保留、独立覆盖复查和浏览器抽验。用户认可该具体 HTML 后方可实施。

## 源码发现与拟修正
- R7 代码复制失败可见反馈；零内容连接中断仍有重试/取回入口；历史失败重试按提示明确标准模式；检索过程的用户手动折叠保持稳定；图片窄栏自适应和加载失败占位；Agent部分草稿保留/丢弃与回退过程中互斥、防重复和错误留稿。当前实际行为与提案分别呈现，来源见包清单，不视为已实施。

## 范围外
本轮无产品代码修改、后端/保存/鉴权/Agent执行语义变化，无 Office 格式专属工具栏设计、设置页重做、原生能力验收或推送。

## 验收
- AC1 R1–R3：所有实际交互入口在清单与 HTML 中可定位，回退与失败分支有明确表达。
- AC2 R4：当前列取自现行源码/真实界面；对比稿可切换模式、主题和尺寸，代表性完整路径通过 GUI 抽验。
- AC3 R5：外部参考有固定版本与具体证据，视觉改进不冒充新业务能力。
- AC4 R6：交付冻结 HTML、覆盖映射、检查记录及本地预览；本轮产品代码零修改，待用户具体认可。
- AC5 R7：上述各项都有实际当前与提案差异以及可操作恢复路径，认可后才实施回归。
