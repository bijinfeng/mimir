# AI对话与生成交互精修

## 目标与背景

第七模块延续已认可的语雀风格，交付覆盖主对话与文档侧栏全部交互的独立 HTML 当前/打磨后对比稿。具体新版获用户认可前不改产品代码。

2026-10-19 用户明确要求「完全去掉，使用 AG-UI 协议和 assistant-ui 支持的交互，不要自定义」。本条针对标注的自定义检索过程块及其替代交互：删除它，不以另一种自定义摘要、时间轴或假模型思考替代。保留现有知识库/文档业务能力，采用官方支持的真实消息类型与组件。

## 需求与范围

- R1 按 packages/chat 与 renderer 宿主实际源码，保留71组379来源状态及稳定ID/锚点。删除的现行入口仍在current列和映射中可追溯，proposed明确标记removed，不能以“全覆盖”强行重新显示。
- R2 覆盖主对话、新建/历史、范围/模型/强度、队列、流式消息/真实模型思考/工具/引用/媒体、停止/失败/重试、笔记保存、Agent中断/截图交接。范围以源码和本次明确删除要求为准，不增加业务能力。
- R3 每适用切片覆盖浅深、窄屏、键盘、hover/focus/pressed/disabled/loading/empty/error/success/cancel/recovery。原生与接口边界单列，映射数量不冒充GUI实测。
- R4 独立HTML以同场景/内容/逻辑尺寸比较，提供完整导航、状态切换和可操作恢复路径；当前列来自源码与真实基线。
- R5 保留已选主题及真实模型绑定/Agent执行合同。WeKnora固定版本与官网证据用于过程/来源/等待反馈参考，不能覆盖用户本次禁止自定义过程的选择。
- R6 v1冻结HTML和哈希不覆盖；修订创建prototype/v2，另记版本/哈希和审批。须完成独立覆盖复查、浏览器代表路径与原型检查。
- R7 保留代码复制失败可见反馈、零内容连接失败重试/取回、历史重试标准模式与提示一致、图片适配/错误占位、部分草稿及回退互斥/失败留稿。v1原定“保留自定义检索过程手动开合”的要求由R8替代；真实reasoning的开合按官方组件合同。
- R8 proposed的所有主/侧栏、实时/历史、运行/完成/失败/停止场景完全移除自定义mimir.trace展示及分词/召回/计数日志；不显示“思考N轮、调用M次工具”，不另造替代过程条。未来产品实施同时停止本轮自定义trace发送与消费；旧历史trace保持数据兼容但不渲染，不做破坏性数据库迁移。
- R9 只有实际存在的AG-UI reasoning/tool-call等消息类型，才接assistant-ui对应官方组件；不把检索trace转换为reasoning/工具调用。复用有固定版本、许可和来源的官方组件源码，保持其交互，允许主题/语言与必要依赖接线适配；不得以手绘近似壳冒充官方件。组件版本兼容须单独核查。当前官方registry依赖的responseDeliveryStatus与产品react SDK 0.15.28存在类型差异；原型隔离使用0.15.29，未来产品接线需受影响SDK最小升级并通过现有AG-UI/Agent回归，不能声称当前产品版本直接完整兼容。

## 业务边界

本轮只修改任务资产和新HTML，无产品代码、API/存储、鉴权、模型/Agent执行或Office工具栏改动；不删除引用、保存、范围、队列、截图和未保存守卫等现有业务能力。本次不是全项目协议迁移或产品依赖升级，不删除旧会话数据。真实工具执行、原生能力和全仓质量门留待新版认可后实施验收，不推送。

## 验收

- AC1 R1–R3：全部实际交互入口/删除项都有来源与可定位状态，失败、取消、恢复路径明确。
- AC2 R4：当前/提案同内容同尺寸，可切换主题/尺寸，代表完整路径通过GUI抽验；无真实请求与存储。
- AC3 R5/R9：外部证据固定版本，官方组件有可验证来源、许可、适配说明；运行时数据不虚构，兼容性结论有具体证据。
- AC4 R6：旧v1哈希不变；v2单独冻结，检查/覆盖/本地预览齐全，未获具体新版认可前不task.py start。
- AC5 R7：剩余拟修正的当前与提案差异及恢复入口均保留，实际产品回归待实施。
- AC6 R8/R9：proposed全场景无自定义trace UI；自定义历史记录不会生成假reasoning/工具调用；真reasoning/tool-call用官方支持的交互。current列保留现行事实并明确当前/提案差异。
