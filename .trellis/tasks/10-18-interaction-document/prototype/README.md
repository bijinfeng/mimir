# 文档阅读与共用流程 · 独立 HTML 对比稿

打开 `review.html`；默认阅读场景 `DOC-009.idle` 与“只看打磨后”。顶部切换当前/提案/同宽上下对比、浅深主题、1024桌面/390窄屏/700中栏/低高度、200%文字与减少动效。“适应窗口”只缩放评审画布，关闭后可按原始像素查看。两侧始终使用相同文章、标题和画布尺寸。

场景源为 `../research/document-scenes.json`：78组、422个枚举状态。左栏支持 ID/页面/状态搜索；每个状态用 `#scene=DOC-xxx.state` 直达。窄屏、低高度和中栏的直达链接同步画布；主题状态同步浅深。422是静态路由数量，不是422次GUI测试；29条渲染轨道复用相同自然hover/focus、等待恢复及宿主交接组件，不把每个自然态画成不同的业务页。

- 产品代码未改，独立 React 源码不导入产品组件、不访问API、不读写真实资料或浏览器存储。
- 当前侧以源码与真实基线截图独立重建，使用同内容fixture；不是所有状态的产品截图或逐像素证明。笔记80px Ribbon为同高静态示意，完整编辑器留第十模块；Office仅展示真实格式宿主、加载/保存边界。没有新增公开分享、读写模式切换、回收站或原件页级引用定位。
- 标题当前侧保留Enter/blur收起、IME与失败留稿缺口；提案侧明确确认/取消、blur留稿、等待锁定、失败留稿。已写入但刷新失败用持久保存状态锁重复写，只重试读取，读取再失败也保留只读恢复入口。
- 整理读状态与写状态分开；候选仅写成功后移除；标签等待单飞、失败留候选；目录失败可实际重读恢复。清空folder如实表示不再归属于知识库，通过搜索/已有标签找到。撤销遵守现有8秒语义，原型用“模拟8秒到期”演示，未伪造后台计时或新恢复能力。
- AI摘要/标签是本次文档临时结果；生成、采用和失败反馈分开。切文档/迟到响应fixture可实际操作。DOC062是DOCX修订开关；DOC063是XLSX能力宿主；DOC058是PPTX截图草稿，移除/预览/显式发送有独立控件。完整Chat流式消息、工具执行、保存笔记留第七模块。
- DOC018当前围栏标题误入大纲如实保留，提案排除；DOC020有重复首/后/跨节点fixture。没有可靠命中时保留正文并反馈，不把Office正文偏移当原件页坐标。
- DOC040仅提案新增已有URL的原网页入口，点击明确标注新前端入口及外站宿主验证。DOC074仅说明浏览器Back/原生刷新关闭现有边界，不承诺本轮新增全局router blocker，不用HTML自制弹窗冒充系统确认。
- 请求结果由画布下“评审模拟”的返回成功/失败控制；无假请求计时器、假上传进度。弹窗等待不能取消/重复提交；F6可到模拟结果条。模拟结果条位于弹窗遮罩之上，是评审控制而非产品功能。
- 原生文件/下载、播放与编解码/Range、外站标签、系统刷新关闭、剪贴板、读屏与Electron仍需实施后宿主验证。媒体控件是无媒体轨的原生控件示意，不能据此声称播放成功。
