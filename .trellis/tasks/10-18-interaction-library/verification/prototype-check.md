## 成功分支与数据一致性

| 分支 | 已核实的本地原型结果 |
|---|---|
| 新建 KB | 名称/描述进入身份区；清空当前记录、目录和位置映射，成为新空库。 |
| 编辑 KB | 身份更新，保留原记录与目录；未改不提交。 |
| 删除 KB | 删除当前库后进入无库引导；文档保留/清空归属的真实后果明确，无恢复承诺。 |
| 新建目录 | 插入独立空目录，保留已有目录及记录；进入新目录为空态。 |
| 重命名目录 | 仅同父级改目标和下级路径；文档来源与当前子树位置跟随，重新筛选正确。 |
| 删除目录 | 仅目标子树移除；其记录设为无归属并退出本库过滤，其他记录保留。 |
| 新建笔记 | 唯一 ID 的“未命名笔记”带当前目录，打开正确新目标。 |
| 重命名笔记 | 按 ID 更新标题，详情与列表同源。 |
| 移动文档 | 按 ID 更新归属，列表/详情/count 派生变化；空目标是无归属。 |
| 撤销移动 | 保存原归属并回写同一 ID；模拟失败不改记录。 |
| 删除文档 | 移除正确 ID，文档条数及目录子树 count 随记录派生。 |
| 替换原件 | 按 ID 更新当前结果状态、大小/提取反馈、日期；不把提取失败当原件未存。 |
| 取消/请求失败 | 不更改已保存记录，草稿保留；committed 刷新重试不二次写入。 |
