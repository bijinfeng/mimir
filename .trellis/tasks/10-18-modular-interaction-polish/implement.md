# 逐模块实施顺序

总任务继续跟踪未展开模块；截至2026-10-18，前六模块已有具体版本实施批准并完成模块验收，外部全仓阻断保留。第七模块对话进入规划，未获得本版HTML实施批准；后续模块不继承批准。

1. 用户认可第一模块具体HTML后，记录版本、哈希和原话，加载相关renderer规范，由Trellis实现/检查流程限定实施。
2. 保留当前工作树的上一轮字段调整；只纳入本轮实际修改。全局token改动须重新评估所有消费者，不用全局CSS代替局部交互修复。
3. 符合认可稿后验证真实页面、异步失败/重试、键盘、浅深/窄屏；按受影响包Quality Check完成质量门，记录局限和证据。
4. 每轮实现与验收完成后按AGENTS.md及时限定提交并记录commit，不混入并发会话、不推送。
5. 按module-map.md进入下一模块，先源码和真实界面盘点、HTML、认可，重复以上流程。功能新增、保存合同改变或新的视觉方案必须重新审阅。
