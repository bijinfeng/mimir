# Mermaid 图表统一使用 Pele

## 目标
用户已试用 Pele，要求验证通过后正式替换 Mermaid，不保留回退引擎。本轮是已授权接入的局部收尾。

## 要求
- mermaid 代码块仅使用现有 Pele 1.6.0 渲染；移除 Mermaid 动态加载、初始化与依赖。
- 继续使用原 Markdown 围栏、编辑与存储协议；WaveDrom、普通代码块保持既有行为。
- Pele 失败时显示可恢复错误，源码保留且可修复、保存、重开与撤销。
- SVG 净化、隔离图片、关闭链接与图片、输入限制保持有效。
- 不改历史试用归档，不扩展配色或布局，不升级 Pele；长中文窄列与主题配置差异沿用试用验收记录，不能声称完整语法兼容或性能收益。

## 验收
- 相关真实引擎、安全与编辑器测试通过，覆盖 Pele 失败后修复与撤销。
- 产品无 Mermaid 引擎导入和直接依赖，锁文件移除不再使用的闭包；mermaid 语法标记保留。
- 使用相同源码、主题和尺寸保存真实组件前后 HTML，验证成功与错误恢复状态。
- 独立审查、完整 pnpm check 通过，同步唯一现行规范并提交本轮代码和证据。

## 变更边界
行为差距只在 diagram-render.ts 的失败分支；其相关测试、renderer/package.json、pnpm-lock.yaml 与 editor/conventions.md 必须同步。父会话负责新验收归档和最终质量门。既有研究见上一轮归档，无需重复竞品调研。
