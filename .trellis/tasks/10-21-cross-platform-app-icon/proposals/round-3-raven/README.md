# 渡鸦 · 第三轮规划稿

用户在看到绿色折带稿后提出动物标识，并明确选择渡鸦。主色保持现行主题绿 `#00834d`，反白为纯白 `#FFFFFF`，深色界面标记用现行强调绿 `#6bdaa5`。

- 原创 SVG 主形由侧身、厚喙、收翅及完整楔形尾部构成；翼部和眼部为 evenodd 负形。没有嵌入字母，也没有导入或描摹第三方鸟形。
- `mark.svg` 为单色源，`app-icon.svg` 为带底版；`icon-preview.png` 是浏览器对实际内联 SVG 的截图。
- `preview.html` 沿用前两版的尺寸、内容框架和四端场景，支持明暗切换。`preview-light.png` / `preview-dark.png` 为 1440px 截图，`preview-mobile.png` 为 390px 截图。
- 在本机 Chrome 对 HTML 和 SVG 进行两轮合并视觉检查。首次 Chrome 启动曾异常退出，重试后成功；没有安装额外浏览器或修改运行环境。
- 主要识别依靠头、喙及整体鸟形；16px 时眼部不作为关键细节。正式接入阶段还要检查真实 favicon 和标题栏，不能以这份规划模拟替代。
- 所有场景均为规划预览，尚未修改产品资源、系统安装或微信后台。前两轮稿保留。
- 字体仅用于提案，来源及许可证沿用第一轮 Manrope 及本目录 OFL 文件。
