# Markdown 笔记编辑页头部改版

## Goal

以 Obsidian 的内容优先、低干扰笔记工作区为参照，使当前笔记更醒目、格式操作更清晰。**头部、工具栏、内容区域三个区域及其顺序保持不变**；标题仍在头部。

## Background

- 当前 `DocumentPanel.tsx:563-700` 把标题、返回、元信息与动作压在 48px 的 Office 式头部；`MarkdownEditor.tsx:610-847` 的约十组命令常显，`shell.css:163-205,556-577` 允许折行并显示组名。审查截图 `../10-10-ui-interaction-audit/audit/23-document-open-navigation.png` 在 1280px 已出现第二行，见 F20–F22。
- Obsidian 官方 [Tabs](https://help.obsidian.md/tabs) 与 [Command palette](https://help.obsidian.md/plugins/command-palette) 描述笔记切换和键盘命令。这里借鉴交互层级，并不声称存在官方像素级视觉规范。

## Requirements

- R1：保留头部、工具栏、内容区域三个独立区域及其顺序；不移动标题，不改正文、大纲、问 AI 侧栏的列数、尺寸和滚动归属。
- R2：Markdown 笔记头部突出标题，弱化次要元信息与返回按钮的视觉重量；问 AI、更多、重命名及显式返回仍可达。长标题不挤掉操作，完整内容可通过 tooltip 或编辑态查看。
- R3：Markdown 工具栏稳定为单行，取消常显组名和自动换行；现有命令及禁用原因全部保留。窄窗口的命令区可独立横向滚动，保存入口固定可达。
- R4：自动保存、手动保存、状态与字数、未保存离开保护的行为不变；保存中和失败仍明显可见。本任务不处理 F1 的“丢弃改动”语义缺陷。
- R5：只改变 Markdown 笔记外观。Office 文件编辑器和只读文档不受影响；浅深主题与 1440／1100／880／600px 视口均需实看，键盘焦点和可访问名称保留。

## Acceptance Criteria

- [x] 1280px 下三个区域顺序不变，工具栏只有一行，正文首段比原截图更早进入首屏。
- [x] 桌面和 600px 下标题、返回、问 AI、更多及保存入口可辨认或有可访问名称；长标题无页面横向溢出。
- [x] 所有现有 Markdown 命令仍可操作或说明禁用原因；窄窗口滚动命令区不影响保存入口。
- [x] 保存状态、字数和离开保护行为保留；Office 编辑器及只读文档无同样的外观变动。
- [x] `pnpm check` 和 `git diff --check` 通过；浅深主题和四个目标宽度的真实截图均已核对。

## Out of Scope

- 新增文档标签页、快速切换器、命令面板、互链或假入口。
- 重构保存逻辑、服务端协议、内容区域列布局或滚动结构。
