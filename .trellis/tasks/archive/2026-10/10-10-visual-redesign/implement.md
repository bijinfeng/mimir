- 复查项目规则、renderer/theme/document、`@mimir/office`、chat、web/desktop 入口规范；记录旧版与方向稿截图。GenOffice 官网只作为顶部工具区和下方画布的视觉参照，工具功能以本仓库为准。

1. 按真实路由和全局组件建立逐屏清单：登录/首次建号与所有认证状态、桌面独立首次使用与关于页、知识库、文档阅读与六格式编辑、主对话空/内容态、设置全部九个 Web 分区及桌面客户端分区、搜索/链接收集/文件上传/新建知识库/确认与错误浮层。
2. 给登录与代表性设置分区补宽屏、窄屏、浅色、深色方向稿；统一浮层的层级、宽度、信息密度和操作顺序，并与现有工作区方向稿一起展示。已完成 `research/visual-full-surface.html` 和 10 张截图，覆盖登录、建号/错误、账号、外观、统计、收集、搜索、确认。
3. 审核每屏现有文案与真实行为，去掉对操作无帮助的解释，保留必要的错误、范围与功能限制说明；核对 `DocChatGuide` 完整指南。
4. 更新 PRD、设计与实施清单，进行新版方案审阅；取得新的明确确认后才继续下面的实施顺序。

## 顺序

代码边界：主题与应用壳只改 renderer 的 theme、`_app.tsx`、`NavSidebar*`；对话视觉在 `packages/chat`，由 renderer 的既有桥接消费；编辑器工具区与图标在 `packages/office`，文档宿主在 renderer；登录、知识库、设置和全局浮层在 renderer 对应页面/组件。并行时这些文件组各有唯一负责人，集成前查看已有未完成的 `NavSidebar.style.ts` 改动，不覆盖其他实施者的文件。

1. **视觉基础**：在现有 Ant Design 6 / antd-style provider 内更新浅深 token、组件级 token、字体角色、表面与选中/焦点/链接颜色；同步真实派生主题的对比度测试。核对 Button、Menu、Input、Modal、Tooltip、Table 的共享状态，明确浏览器与桌面顶部 chrome 的差异。完成后先看空壳与基础控件，避免页面级局部值四处覆盖。
2. **应用壳与导航**：改造 `routes/_app.tsx` 与 `NavSidebar` 为功能栏 + 当前任务侧栏 + 主区；保留库树、会话、快捷搜索、收集、账户设置和折叠偏好。定义 1100/880/600px 布局与键盘/无障碍名称。先验证导航、深链和窄窗口。
3. **代表页面**：依次调整知识库、文档阅读态和编辑态（含大纲、顶部工具区、格式画布和状态行）、主对话空态与回答态、文档阅读助手、设置（宽屏分区栏、窄屏 Select、模型供应商与任务分配）。优先调整容器结构与空间分配，再统一行、按钮、菜单、引用、空态等组件形态。六种编辑器沿用 `EditorShell` 槽位与真实命令，文档侧栏复用 `ChatPanel`。每页在浅/深、宽/窄截图复查后再到下一页。
4. **图标统一**：清点 renderer、chat、desktop 和 Office 的 UI 图标；常规操作统一用 `lucide-react`。Office 的 `shell/icons.tsx` 保持既有导出名、改为 Lucide 适配或明确文字标签；给 Office 增加依赖，确认无产品代码引用后移除 renderer 的 `@ant-design/icons` 依赖。检查大小、描边、基线、焦点与图标按钮名称。品牌标记与文档内容 SVG 保留。
5. **入口、设置与帮助内容**：登录/建号和桌面首次使用页按入口任务重构布局及全部状态；桌面关于页只保留用户需要的版本与使用方式。设置的九个 Web 分区及桌面客户端分区逐一调整信息层级、字段组与操作反馈；插件清单呈现为用户能理解的支持能力。新安装附带的说明改为简短使用指南，既有笔记不自动覆盖。
6. **全局浮层与状态**：命令搜索、链接收集与文件上传、新建知识库、删除/未保存确认、加载失败与空态逐一收口。文档阅读助手指南保留；不改上一轮的交互语义和精简文案。
7. **收口**：更新设计规范与必要的架构/样式约定，特别替换旧蓝色、旧宽度及 `@ant-design/icons` 决定；删除被替代的旧数值和过时注释；对真实页面与方向稿作逐屏对照并记录偏差原因。

## 验证

- `pnpm check`，并运行涉及的主题、导航、设置、文档、对话行为测试；只补对跨断点导航、URL 分区和主题对比度有价值的测试。
- 浏览器实际验证：知识库、文档阅读与六格式编辑、主对话空态/回答态、文档侧栏、模型设置空/配置态、登录、搜索、收集；至少 1440、1100、880、600px；浅色与深色。核对溢出、焦点、主操作可见、工具区与画布层级、保存状态、范围/强度选择、模型设置跳转、引用跳转和完整阅读助手指南。
- 桌面壳有可用运行环境时核对真实标题栏；否则代码审查与 Web 共用 renderer 边界，并在结论中注明限制。真实收费模型、外部抓取和 Office/PDF 深度编辑不属于此次视觉验收。
- `git diff --check`，审阅变更范围与遗留旧蓝色/旧宽度；记录前后截图和明确的未覆盖边界。
- 对变更的 antd 控件先用 `antd info/semantic/token --version 6.6.4 --format json` 核对 API，再运行 `antd lint` 及全仓图标 import 检查；检查 Office 六格式图标适配后的命令、Tooltip 与快捷键没有变化。

## 回退点

- 基础 token 与应用壳先作为一个可独立审查的阶段；若主题或布局导致系统性退化，先回退此阶段，不把逐页样式继续叠加。
- 页面视觉改动与功能契约分离；验证失败时回退对应页面容器与样式，保留已验证的主题和导航。
