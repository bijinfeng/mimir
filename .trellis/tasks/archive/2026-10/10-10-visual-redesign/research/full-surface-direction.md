# 全页面补充方向（实施暂停期间）

这份方向补足首轮工作区稿未覆盖的入口页、设置分区和全局浮层。它只规定布局、内容层级与状态，不新增产品功能。正式视觉稿与页面实测仍需在恢复实施前完成审阅。

## 页面清单

| 入口 | 需要呈现的状态 | 主要视觉任务 |
| --- | --- | --- |
| `/login` | 首次创建账号、日常登录、加载、本地模式、请求/表单错误、提交中 | 形成独立且克制的入口，不沿用旧版 400px 居中卡片 |
| `/docs` | 文件夹/文档列表、空态、加载/失败、列表/卡片、增删改 | 工作区的扫描效率和文件操作层级 |
| 文档详情 | 阅读、问答指南、引用跳转、编辑与六格式画布 | 阅读焦点与 Office 式编辑秩序 |
| `/chat` | 空态、会话、检索过程、引用、输入/模型入口 | 消息与输入优先，内容和来源邻近 |
| `/settings` | 模型、检索、订阅、存储、插件、统计、数据与备份、外观、账号；桌面增加客户端 | 同一分区栏，按内容形态分别设计正文 |
| 全局浮层 | 命令搜索、收集链接/文件、上传、新建知识库、删除/未保存确认、加载失败 | 与主工作区同一层级和操作语言 |

`/` 目前直接进入 `/docs`，不设计虚构首页。全局小菜单、Tooltip 和通知也使用同一色彩、圆角、边界、阴影和焦点规则。

## 登录与首次建号

宽屏采用 40:60 左右分区：左侧是安静的品牌面，只放标记、产品名与“知识工作区”定位；右侧是约 400px 的表单列，含明确标题、字段、主按钮与必要反馈。背景直接使用主题的外壳/工作面两级，不叠一张悬浮卡，也不放功能清单、统计数字或营销插画。左侧品牌面的信息量需控制在一眼可扫完的范围。

```text
宽屏                                    窄屏
┌───────────────┬───────────────────────┐   ┌─────────────────┐
│ 标记  mimir   │  登录 / 创建账号       │   │ 标记  mimir     │
│ 一句产品说明   │  状态/错误            │   │ 登录/创建账号   │
│               │  邮箱                 │   │ 状态/错误       │
│               │  密码 [确认密码]      │   │ 字段与主按钮    │
│               │  主按钮               │   │ 必要的次入口    │
└───────────────┴───────────────────────┘   └─────────────────┘
```

窄屏以单列呈现，品牌缩为页首，不浪费首屏高度。加载态保持表单区域的空间位置；错误贴近表单顶部且持续可见，字段错误贴近字段。首次建号只增加确认密码和必需的说明。桌面客户端的“更换使用方式”仍在表单次操作位；本地模式以明确返回客户端的行动替代表单。保留真实桌面标题栏，不在浏览器画窗口控件。

## 设置所有分区

设置侧栏负责位置，正文顶部只出现本分区标题和一句必要说明。每一组以细分隔和留白区分，不套多层卡片。字段用“标签—当前值/控件—反馈”的一致对齐方式，操作按钮紧贴所作用的组。禁用或只读状态要直接说明真实原因。

| 内容形态 | 分区 | 正文构图 |
| --- | --- | --- |
| 连接与分配 | 模型 | 供应商列表在前，配置编辑与四类任务绑定在后；就绪/测试状态靠近对应项 |
| 配置与状态 | 检索、订阅、存储、插件 | 关键状态在页首，设置项按任务分组；无配置与读取失败给可恢复入口 |
| 数据阅读与操作 | 统计、数据与备份 | 数值或趋势为主，导出/重建等操作形成独立、明确的操作组 |
| 个人与设备 | 外观、账号、客户端 | 控件短、标签清楚；主题预览和当前选择同屏可辨；客户端只在桌面显示 |

宽屏分区栏约 246px，正文最大约 730px；窄屏使用带名称的 Select，并保留相同内容顺序。URL 的 `?section=` 继续定位分区。所有分区需分别查看有数据、无数据、失败及禁用情况，不能只用模型页替代整页验收。

## 全局浮层

- **命令搜索**：输入位于顶部；结果按名称、来源、快捷键的层级排版，选中行与键盘焦点清楚。窄屏限制浮层宽度和高度，结果在内部滚动。
- **收集与上传**：当前入口为粘贴链接与上传文件两种方式，切换条在上，当前表单/拖放区域在下；进度、成功与失败位于对应任务内。主按钮明确当前动作，避免多个强调按钮争夺注意力。
- **新建知识库与确认**：标题说明对象，字段或后果在中部，取消与确认在底部固定顺序。删除和未保存状态保留清楚后果与安全默认动作。
- **错误与空态**：区分“没有内容”和“读取失败”；失败显示重试，空态显示当前任务最直接的下一步。两者不共享误导性插画或标题。

以上浮层采用同一表面、边框、焦点与阴影规则，但宽度按任务内容确定；不把命令搜索、上传和确认强行做成同尺寸弹窗。
