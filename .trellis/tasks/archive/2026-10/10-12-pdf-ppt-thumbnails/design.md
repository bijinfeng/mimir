# 技术设计：PDF/PPTX 缩略图与页级操作

## 边界

- `packages/office/src/editors/` 新增共享页栏组件及样式；PDF、PPTX 各自提供页标识、缩略图渲染、导航与动作回调。`EditorShell` 的通用工具条和右侧附属面板保持原有契约。
- PDF 页数据继续以 `PdfPageRef[]` 为真相，所有侧栏动作进入现有 `applyPages` / `goTo`；PPTX 页数据进入 `PptxEditSession` 的结构操作，由 `view()` 更新画布与缩略图。两者都不另存一份与编辑状态脱节的缩略图顺序。
- 页栏是普通控件区：缩略图右键打开 antd 页操作菜单；页项的菜单键或 Shift+F10 打开同一菜单，不显示显眼的逐页“更多”按钮。预览图本身不响应编辑点击。拖拽仅处理同一文档中的页重排，并提供菜单中的“上移/下移”作为键盘路径。

## 界面与数据流

1. 工具条下方左右分栏：左侧固定宽度、独立纵向滚动，右侧原主画布滚动。缩略图使用文档宽高比，页码位于图下，选中态以主题边框与背景表达；当前页变动时滚入可视区。
2. 侧栏顶部“新增页”，缩略图右键菜单包含复制、删除、上移、下移；拖动页项时显示落点。新增与复制都插在目标页之后并选中；删除后选中邻近页；拖动后选中被移动页。
3. 用 IntersectionObserver 或等价的可见区调度仅渲染当前页及邻近可见页；文档切换和内容/旋转变化时缓存按来源与版本失效。缩略图错误只影响对应项，主画布仍可使用。
4. 宽度较窄的编辑区用可切换的缩略图面板，关闭时主画布占满；切换入口始终可达。浅深主题、焦点环和最小宽度遵循项目设计契约。

## PDF

- 缩略图沿用 `sourceOf` 的原件、导入件或空白页来源；低分辨率调用 pdf.js 并展示旋转。待生效的裁剪/纸型与主画布遵循同一显示边界，不伪装成已经保存后的内容。
- 复制 `PdfPageRef` 时生成独立数组项，保留来源、旋转、裁剪、纸型；`buildPdfBytes` 的 `copyPages` 支持重复索引，补回归测试。新增仍用现有 A4 空白页。
- 将 `pdf-render.ts` 的全局代次改为按 canvas 管理，单个画布的快速重绘仍只保留最新一次，但不同缩略图与主画布可并发完成；卸载时释放各自渲染句柄，延续现有文档缓存与延迟销毁机制。

## PPTX

- `PptxEditSession` 增加 `insertBlank`、`duplicate`、`remove`、`move`，结构变化使 `view()` 快照失效并计入 `hasChanges()`；保留原有文字/格式编辑路径。最后一页不可删除。
- 幻灯片当前顺序从会话的 `slides` 得出；保存时在 `ppt/presentation.xml` 的 `<p:sldIdLst>` 中按目标顺序补丁修改 `<p:sldId>`，并在 `ppt/_rels/presentation.xml.rels` 增删对应关系。新幻灯片分配唯一的 slide 部件名、slide ID 与关系 ID，更新 `[Content_Types].xml`；未变的 XML 片段和 zip 条目原样透传。
- 新建页写同画布尺寸的空白 `p:sld`，关系指向现有可用版式；复制页从源页当前补丁结果复制 XML 与幻灯片关系表，新模型与原页分离，媒体/主题/母版等只读资源继续共享。含 notes、comments 等需要独立反向引用的页，复制前须显式处理或给出清楚的拒绝理由，不能生成有歧义的包。
- 删除页移除演示文稿中的引用及该页独占的 slide XML/rels；保留可能被其他部件共享的媒体/版式等资源，避免误删。若自定义放映、分节等外部结构引用目标 slide ID，需同步补丁或安全拒绝。
- `save()` 先生成字节，不改变会话；成功写回后的 `commit()` 同步结构基线、生成部件与元素锚点。连续保存和“先改字再复制/排序”必须读回一致。只改文字的文件差异断言保持原样。

## 验证和风险

- 单元与集成测试读取保存后的 PDF/PPTX，断言顺序、内容、页数、媒体及二次保存；对 PPTX 比较 zip 条目，确认无关部件不变。用现有 PNG 图片幻灯片夹具扩充多页夹具。
- 浏览器实际查看多页 PDF/PPTX：缩略图内容、滚动、选择、拖拽落点、操作菜单、窄窗与深色；保存后重新打开。若独立 PowerPoint 解析器可用，额外读回验证。
- 主要风险是 OOXML 关系与现有未建模扩展；用最小 XML 补丁、拒绝不安全结构和文件读回测试控制。PDF 大文件风险由按需渲染与按 canvas 的代次控制。
