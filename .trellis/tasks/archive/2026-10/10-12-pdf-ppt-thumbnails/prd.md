# PDF 和 PPT 左侧缩略图导航与页级操作

## Goal

在 PDF 与 PPTX 编辑器左侧提供与文档内容一致的逐页缩略图，让用户快速定位页面，并直接完成常见页级操作。

## Background

- 用户截图展示左侧纵向缩略图栏、边框、页码与右侧独立主画布。
- 当前 PDF 已有逐页渲染和新增空白页、删除、调序等工具条动作；PPTX 已有逐张 SVG 渲染，但编辑会话只支持文字和整段格式修改。PPTX 页级操作必须在补丁保存路径中新增结构写入。
- 用户明确要求缩略图栏除导航外，一起支持新增、复制、删除、拖拽排序。

## Requirements

1. **R1 内容与定位**：PDF 与 PPTX 均显示真实内容的纵向缩略图、页码和明显的当前页状态；切换文件、工具条跳页或查找跨页命中时保持同步。
2. **R2 导航与布局**：点击缩略图切换主画布；缩略图列独立滚动。宽度受限时仍能访问缩略图与主画布，工具条、保存入口不溢出。
3. **R3 页级操作**：两种格式均可从缩略图栏在当前页后新增空白页、复制指定页、删除指定页，以及拖拽改变页序；操作后选中页、页码与主画布立即更新。保留 PDF 现有的导入、旋转、裁剪、纸型和工具条页序操作。
4. **R4 操作入口与可访问性**：页级操作放在缩略图右键菜单，不显示显眼的逐页“更多”按钮。页项可用键盘聚焦和激活，并能用菜单键或 Shift+F10 打开同一菜单；提供不依赖拖拽的排序入口。新增、复制、删除有清楚名称及禁用原因。两种格式都不能删除最后一页。
5. **R5 保存与保真**：保存后重新打开，页数、顺序、内容、当前格式均正确。PPTX 结构编辑只改必要的包部件；未触及的主题、母版、媒体、其他幻灯片保持原样。遇到不能安全保留的结构时明确报错，不能静默丢内容。
6. **R6 性能**：多页文件仍能优先显示当前页；缩略图按需渲染，不让整份 PDF 的 worker 渲染或大量 PPTX SVG 阻塞首屏。

## Acceptance Criteria

- [x] A1 多页 PDF 与 PPTX 打开时，左侧每页显示可辨认的内容与页码，右侧显示选中页；点击、工具条跳页、查找跳页后两侧一致。（R1、R2）
- [x] A2 从侧栏新增、从缩略图右键菜单复制/删除/排序或拖拽排序后，列表、主画布、页码及保存状态立即一致；无显眼的逐页“更多”按钮；删除最后一页不可用；键盘能打开菜单并完成相同排序。（R3、R4）
- [x] A3 PDF 的导入页、空白页、旋转页均能显示对应缩略图；复制后独立成为两页，保存并重新打开仍正确。（R3、R5）
- [x] A4 PPTX 含文字与图片的幻灯片在复制和调序后可重新打开，内容及资源仍可渲染；新增空白页可保存并重新打开；单纯文字编辑仍满足既有补丁保真测试。（R3、R5）
- [x] A5 缩略图栏可独立滚动，窄编辑区、浅色与深色下可见且主要操作可达；大量页面时当前页优先渲染。（R2、R4、R6）
- [x] A6 `pnpm check` 通过，并实际查看 PDF/PPTX 界面与保存后的文件效果。（R1–R6）

## Out of Scope

- 多页选择、批量操作、跨文件拖拽、右键菜单、PPTX 元素位置编辑。
- 旧式二进制 `.ppt` 的解析和编辑；本任务针对当前产品支持的 `.pptx`。
- PDF 正文文字编辑或改变现有 PDF 整体重建保存策略。

## Technical Constraint

- PPTX 页级结构需更新 `presentation.xml` 的顺序、演示文稿关系表及必要的内容类型与新幻灯片部件；原有补丁式文字保存行为必须保留。
- PDF 的主画布与缩略图都使用 pdf.js；当前渲染代次是模块级全局值，规划中需调整为互不取消的渲染范围。
