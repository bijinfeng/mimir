# 设计 Mimir 产品官网

## Goal

让首次了解 mimir 的个人知识工作者看懂产品价值，并进入现有工作区开始使用。核心承诺：笔记、网页与文件收进自己的知识库，AI 回答能回到原文核对。

## Background and evidence

- 产品边界由 `.trellis/spec/project/product.md`、`apps/web/PRODUCT.md` 与 `apps/desktop/PRODUCT.md` 定义：单用户知识库，覆盖收集、整理、检索、使用与沉淀。已有 Markdown 笔记、网页/公众号/GitHub 收集、文件保留与正文检索、全文搜索、原文引用问答、摘要/标签建议、RSS，以及已实现范围内的 Office/PDF 能力。
- 页面布局与个人知识场景主参考 Obsidian 官网 2026-10-20 快照；知识库与引用语义检查 WeKnora 官网、公开 v0.8.3 release 与固定 tag commit `3e22822c1d2397be730c458c7539d0eb8c113a24`。本次源码下载受限，补充检查仓库此前保存的同 SHA `weknora-theme.css:195` 细边、焦点与中性选中规则；不将其当作 Office 工具栏模型。
- 外部记录与适用边界见 `research/reference-review.md`、`research/evidence.json`；原文快照见 `research/weknora-home.txt`、`research/obsidian-home.txt`。

## Requirements

- R1：官网作为浏览器 Web 的公开 `/` 首页，主行动“开始使用”进入现有工作区；未登录经过既有登录流程，已登录直接访问。桌面本机继续直达工作区。首页无需个人数据和可用的认证 API。
- R2：采用已选“问题带路”结构。首屏标题“记过的知识，此刻用得上。”，说明“笔记、网页与文件，收进自己的知识库。用 AI 找回线索，每个答案都能核对原文。”；右侧展示问题、示例回答与引用，次行动“看看怎么工作”通往页内说明。选择凭据为 `.impeccable/questions/3a7b9f59.answer.json`，optionId=question。
- R3：下接真实组件渲染的工作区演示、收集/检索/引用闭环、数据掌控、本机与自托管服务器两种使用方式、FAQ、末尾行动入口。演示明确标注示例，不读取用户私人资料；引用点击能展开/定位对应示例原文。
- R4：继承现有小写 mimir 名称、BrandMark/BrandLockup、白灰中性表面、工作台绿与系统中文字体。官网可扩大标题和留白，工作区主题不因此变化。
- R5：解释原件与笔记可保留/导出、本机与服务器数据各自独立、连接服务器不等于自动同步、AI 可用性取决于已配置模型。下载和部署链接只指向已核实的真实入口。
- R6：桌面与窄屏、浅深外观均可读可操作，支持键盘、语义标题、跳至正文和减少动效。保持 Web basepath 部署行为；根页面公开不扩大其他页面或 API 的访问权限。

## Acceptance Criteria

- AC1（R1、R2）：1440×900 与 390×844 首屏可见产品定位及开始使用入口；公开首页在会话 API 不可用时仍显示。
- AC2（R2、R3）：示例问题、回答、引用、原文关系完整；键盘/指针点击引用均能查看对应示例段落，收起后焦点合理。
- AC3（R3、R5）：能力、数据与部署、FAQ 均有实际内容；无虚构价格、下载、客户、指标或未落地能力。
- AC4（R4、R6）：1440px 与 390px 无页面横向溢出；浅深主题文字可读、导航与主行动可达；减少动效设置下不播放演示动效。
- AC5（R1、R6）：路由测试覆盖公开首页、受保护页面、登录目标保留、已登录进入工作区、桌面默认入口、API 错误恢复和 basepath。
- AC6：`pnpm check`、Web 生产构建及受影响桌面类型/构建验证通过；保存真实组件 HTML 对比、截图、覆盖清单与验证结果，旧归档保留。官网为新增页面，旧版基线如实记录为 `/` 重定向行为。

## Out of scope

- 新增后端产品能力、账号管理、支付、团队权限、公开发布、知识图谱或插件市场。
- 自动同步本机与服务器数据、浏览器独立离线知识库、无条件离线 AI 承诺。
- SSR/SSG 框架迁移、第三方分析、外部发布或推送；SPA 的搜索引擎收录局限本轮保留。
