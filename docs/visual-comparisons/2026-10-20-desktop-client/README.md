## 这轮实际改变

1. 设置 › 客户端增加真实版本和“关于 mimir”入口，以前 `/client/about` 没有可达入口。
2. 平台契约增加桌面 `openAbout`，由桌面入口自己的路由树提供，共享层不生成 `/client/*` 路由。
3. 关于页增加返回控制；更新状态按钮仍复用更新详情窗口。
4. 原生应用菜单增加“关于 mimir”，跨本地/云端显示版本与当前使用方式。
5. 更新页正文在内容较少时成组居中，内容变长时从顶部滚动，页脚保持固定。
