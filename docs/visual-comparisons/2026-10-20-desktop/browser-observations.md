# 实际浏览器验收

2026-10-20，IAB，真实 Desktop React 组件与产品主题，模拟 preload 形状的桥。不是原生 IPC GUI 验收。

- 生产默认1440×900首启布局另以真实组件补验，见 captures/default-1440x900.jpg；不是实际原生窗口截图。
- 八组同场景/内容/主题/尺寸前后见 comparison.html。截图原始字节实际为 JPEG，历史 .png 文件名保持不变；媒体/尺寸/hash 见 capture-manifest.json。about 窄屏首次截图遇到视口切换竞争（390×234），保留于 superseded，重采390×400后才通过配对验证。
- 读取配置未结算时显示品牌与状态，并保留最小化、关闭；实际点击向模拟桥记录各一次。基线是空白页。
- 800×480 服务器配置初始主操作底部从508.31降至462.31；内容仍可局部滚动。390×400只是压力条件，主进程没有声明最小尺寸。
- 空白地址 Enter 没有 mode.choose 日志；有效地址 Enter 进入等待，字段、选项与返回锁定。手动失败后保留完整 URL，重试成功后记录一次 activate，并保持等待导航状态。补充截图 submit-retry-success.jpg。同帧防重复由挂载 deferred 回归验证，浏览器顺序操作不冒充同帧竞态。
- 配置读取失败重试后恢复带地址的切换页；关于页 QueryClient 前三次失败显示错误，点击重试后恢复版本和模式。
- 桥缺失时显示“这个窗口不是桌面客户端”，开始使用禁用。
- 标题栏折叠/展开标签随状态更新；最大化变“向下还原”，模拟外部事件恢复“最大化”；最小化和关闭各记录模拟调用。darwin 不渲染 Windows/Linux 控件，不伪造原生红绿灯。
- 键盘从最小化 Shift+Tab 聚焦折叠按钮，显示 Mimir focusRing；基线本来具有浏览器默认焦点，不能称其完全没有焦点。
- 关于长版本号两版均无横向溢出，当前版通过密度降低使纵向内容由513压到409像素，未夸大为基线横向故障。

原生补充：server 构建、desktop main/preload/renderer 构建通过；smoke.mjs 启动真实 Electron，12条本地/首启/云端隔离断言通过（native-smoke.txt）。Mac 锁屏阻止原生 UI 控制，未手工验原生拖拽、系统菜单/对话框、红绿灯和真实模式导航；不能用浏览器模拟桥替代这些证据。
