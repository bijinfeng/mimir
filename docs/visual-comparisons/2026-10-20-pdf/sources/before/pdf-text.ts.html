  1. /**
  2.  * PDF 的文字层：**查得到、指得准**。
  3.  *
  4.  * ## 它是什么、不是什么
  5.  *
  6.  * | 做 | 不做 |
  7.  * |---|---|
  8.  * | 用 pdf.js 的 `getTextContent()` 取出每页的文字与位置 | **改文字**——那要 PDFium 确认内容流对象并写回 |
  9.  * | 在整份文档里找一个串，报出共几处、当前第几处 | 正则、通配符 |
  10.  * | 把命中换算成**页面比例矩形**，画在 canvas 上 | 拖拽任意字符选区、复制文字 |
  11.  * | 点选一个完整文字项并保留其 PDF 用户空间矩形 | 仅凭近似查找高亮进行文字替换 |
  12.  *
  13.  * ## 为什么矩形是「比例」而不是像素
  14.  *
  15.  * 画布宽度随缩放变（40%–240%），而命中矩形属于**同一次渲染的坐标系**。
  16.  * 存比例（0..1）的话，缩放、换页、换 DPI 都不用重算文字层——四个百分比直接
  17.  * 跟着走。存像素就必须在每次缩放时重算一遍，而漏算一处症状是「放大之后高亮
  18.  * 跑偏」，不报错。
  19.  *
  20.  * ## 旋转：矩形与画面用**同一个 viewport**
  21.  *
  22.  * `rects` 由 `page.getViewport({ scale: 1, rotation })` 换算，`rotation` 就是
  23.  * 画布渲染时传的那个（`PdfPageRef.rotation`，绝对值）。包括原件自带的 /Rotate
  24.  * （它已经并进 `rotation` 里了）。所以文字层与画面**必然**对齐——不自己写
  25.  * 四个角度的变换矩阵，那四份 case 里平时只看得见一份。
  26.  *
  27.  * 代价是旋转变了要重算矩形。为此**原始文字（pdf.js 的 `TextItem`）单独缓存**：
  28.  * 重算只做一次坐标变换，不重新解析 PDF 的文字（那才是慢的那一步）。
  29.  *
  30.  * ## 裁剪与纸型**不在这里算**
  31.  *
  32.  * 它们是「保存后才生效」的改动，而画布画的是**原件**（`source.bytes`，未裁剪
  33.  * 未换纸）。文字层要跟画布对齐，所以它也只认原件。拿待生效的裁剪去缩文字层
  34.  * 会得到「高亮在画面外面」——那是两套坐标系。
  35.  *
  36.  * ## 为什么先建索引、搜索是同步的
  37.  *
  38.  * `FindAdapter.search` 按契约**同步返回匹配数**（`EditorShell.tsx` 的
  39.  * `FindAdapter`），而 `getTextContent()` 是异步的。所以文字在打开查找之前
  40.  * 先扫一遍（异步、可取消），搜索本身在内存里同步做。反过来（在 `search` 里
  41.  * 发起异步扫描）会让匹配数晚一拍到——栏上显示的是上一次的结果，那看起来
  42.  * 就是「搜不到」。
  43.  */

  408. /** `text` 里所有命中区间（`[start, end)`） */
    409.

    function findRanges(text: string, query: string, options: FindOptions): [number, number][] {
    
    
    410. 
    
  410.   const out: [number, number][] = []
    411. 
    
  411.   const last = text.length - query.length
    412. 
    
  412.   for (let at = 0; at <= last; at += 1) {
    413. 
    
  413.     if (!matchAt(text, at, query, options)) continue

  414.     out.push([at, at + query.length])

    function matchAt(text: string, at: number, query: string, options: FindOptions): boolean {
    
    
    422.

    423.

    455. 
    
  455.     if (chunkStart === undefined) continue

  456.     const chunkEnd = chunkStart + chunk.text.length
    457. 
    
  457.     // 命中区间与这一段没有交集
