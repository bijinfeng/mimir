让知识重新参与思考。

一篇笔记、一份文件、偶然读到的网页。把它们放到一起，在下次需要时，用自己的话找到它。

随手收进来

写 Markdown 笔记，粘贴网页、公众号或 GitHub 链接，上传文件。用目录与标签，让资料逐渐有序。

带着问题找

记得关键词，就直接搜索；只有一个模糊的想法，也可以向知识库提问。让分散的线索重新相遇。

回到原文核对

AI 回答附上来源引用，点击回到对应原文。看清出处和上下文，再形成自己的判断。

知识留在
自己手里。

真正重要的，是多年以后仍能打开这些内容。Mimir 保留笔记与原件，也保留把它们带走的出口。

笔记是 Markdown，文件保留原件
自己的文字使用开放格式保存。上传的文件保留原件，阅读、检索与引用围绕同一份资料展开。
随时导出，而非从头搬家
知识库支持全量导出，包含笔记与上传的原件。备份、迁移或换一种工具，都有可带走的内容。
数据归属清楚，模型选择自主
本机资料存在自己的设备，服务器资料由自己的部署管理。AI 使用你配置的模型服务；发起调用时，相关内容会发送给该服务。
