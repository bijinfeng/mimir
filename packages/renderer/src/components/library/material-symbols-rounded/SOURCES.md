# Material Symbols Rounded assets

The SVG files in this directory are selected **Material Symbols Rounded** icons from
Google's official [Material Design Icons](https://github.com/google/material-design-icons)
project. They are distributed under the Apache License 2.0 license in [`LICENSE`](./LICENSE).

Source URL pattern (retrieved 2026-10-12):
`https://fonts.gstatic.com/s/i/short-term/release/materialsymbolsrounded/{icon}/default/24px.svg`

Icons: `description`, `table_chart`, `slideshow`, `picture_as_pdf`, `code`,
`notes`, `image`, `audio_file`, `video_file`, `folder_zip`, `draft`, `article`.

Only these generic file-type pictograms are used. Google Workspace product marks are
not included. The SVG paths are preserved; Mimir applies theme-aware colors through
CSS masks.
